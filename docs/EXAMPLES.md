# 例子怎么选（场景库）

规矩在 `docs/MAINTAINING.md` 的「怎么写」和 `docs/WRITERS.md` 的 Examples：例子要照顾到各种读者，哪个国家的都成立，先讲痛点再讲办法，品牌只提 Mac 自带的 App 和官方 Wiki 自己提到的。这一份记的是每页已经用了谁、什么事、哪个键，写新页或改例子前先看一眼，挑还没用过的。

`npm run check` 里的 `scripts/check-examples.mjs` 会拦两样：

- 不该出现的例子词：别的聊天、支付、购物、办公软件的牌子（微信、Slack、PayPal、淘宝、Notion、Gmail……），只有某个国家才有的东西（证件号、节日、升学考试、邮编、币种）。网址里的不算。官方 Wiki 自己提到的（Chrome、Dropbox、BBEdit、Photoshop……）不拦。
- 套话：同一句话出现在 3 个以上页面的正文里，或者 2 个页面的 `Copy` 里（中文页和它的 `/en/` 双胞胎算一页）。读者翻两页就看出来是照模板填的。

## 挑例子的三条

1. **一页一个人，换着来。** 下面的表里哪种人已经多了，新页就换一种。同一种人也换一件事：都是找工作的人，一页写求职信，另一页就别再写投申请。
2. **在哪个国家都成立。** 写「学校网页上的通知」「接单网站」「网页系统」，不写具体的网站和 App；钱不写币种；日子写「每月最后一个周五」这种，不写节日。
3. **开头别撞车。** 不要每页都用「你是不是也……」「照这一页做完」/ "If you…" "When you finish this page" 开头，先从那件事本身写起。

## 热键不要撞

读者可能把几页的宏都做了，所以一个键只给一个宏。新手入门和完整教程已经用了：⌃⌥⌘N（第 1 课，备忘录）、⌃⌥⌘T（第 3 课，开工）、⌃⌥⌘W（第 1 步，宏组的开关示例）、⌃⌘A、⌃⌘T（第 3、4 步）。How-to 用的见上表。要用同一个 App 的宏（比如备忘录），说「第 1 课已经做过」，别让读者再建一个同样的键。

缩写同理：第 2 课是 `=reply=`，`=addr=`、`=em=` 是讲规矩时的例子，text-snippets 是 `=ship=`、`=sig=`、`=ret=`，insert-date 提到 `=next=`。
