开一家小网店的人，每天回得最多的就是那几句话：谢谢你下单，两个工作日内寄出，单号会发邮件告诉你。一天回二十封邮件，这句话就要打二十遍，打得快了还会漏半句。照这一页做完，你在 Mail 或任何能打字的地方敲出 `=ship=`，这六个字符会自己删掉，换成那一整段回复；签名和退换说明也一样，各有自己的缩写。

还没做过第一个缩写的话，先走一遍[新手入门第 2 课](/start/2-type-less/)，那里从打开编辑器讲起。这一页接着往下讲：缩写多了以后怎么起名字，长段文字为什么要用粘贴，还有哪些地方它天生不灵。

## 缩写为什么要前后加个等号

<Term k="输入字符串触发器" /> 一直看着你打的字，一旦最后打出的那几个字和你设的那一串对上，宏就开始跑。所以缩写要是一个平常会出现的词，它就会在你不想要的时候冒出来。官方举的例子是给邮箱地址设 `em`，结果你打 them 的时候它也触发了；他们的建议是给缩写加一个固定的前缀或后缀，比如写成 `=em=`，这种组合你平常根本不会打出来（见 [Typed String trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。

<mark>前后各加一个等号，缩写就只在你叫它的时候出来。</mark> 本站的例子都用这一种写法：`=ship=`、`=sig=`、`=ret=`。全站只用一种，记起来也省事，你打出一个等号，心里就知道自己在叫一条缩写。

## 先做发货回复这一条

先给这些缩写安个家。在编辑器左边宏组列表的底下点「+」，新建一个<Term k="宏组" />，叫「缩写」。宏组默认在所有 App 里都生效，这正合适，因为回复有时在 Mail 里写，有时在网页上的客服框里写。

在这个宏组里新建一个宏，名字就写「=ship= 发货回复」，以后在列表里一眼就认得出。接着加一个触发器，选 **Typed String**（输入字符串），在 **This string is typed:** 后面填 `=ship=`；它下面那个「执行前先删掉打出的字」的选项要勾上，这样 `=ship=` 会先消失，回复才出现。然后加一个动作 **Insert Text by Pasting**（粘贴插入文字），把回复写进去：

<Copy id="ts-ship" title="=ship= 展开后的回复" code="谢谢你下单！包裹会在两个工作日内寄出，寄出以后我把单号发邮件告诉你。有任何问题，直接回这封邮件就行。" />

Keyboard Maestro 没有保存按钮，改完几秒钟就自己存好了。

## 为什么用粘贴，不用打字

插入文字有两个常用的动作。**Insert Text by Typing**（模拟打字插入）像你自己一个键一个键地敲，适合键盘上一两下就能打出来的字，长度大约三四十个字符以内，再长就慢了，表情符号也打不出来。**Insert Text by Pasting** 先把文字放进剪贴板，再替你按一下 ⌘V（⌘ 是 Command 键），多长都是一下子出来，什么字符都行，换行也原样留着，不会被当成回车去按了网页上的按钮。它的代价是会顶掉你剪贴板里原来的东西，两者的比较见官方的 [Insert Text](https://wiki.keyboardmaestro.com/action/Insert_Text)。

中文本来就不是一个键一个字打出来的，签名又常常有好几行，所以缩写一律用 **Insert Text by Pasting** 最省心。剪贴板被顶掉也不用太担心：Keyboard Maestro 的<Term k="剪贴板历史" />记着你前几次复制的东西，需要时还能找回来，见[完整教程第 5 步](/guide/5-clipboard/)。

## 再做两条：签名和退换说明

照上面的样子在同一个宏组里再建两个宏。签名有三行，正好看出粘贴的好处，换行一个不少：

<Copy id="ts-sig" title="=sig= 展开后的签名" code={`祝好，
Mia
绿角落小店，周一到周五 9:00 到 18:00 回复消息`} />

退换说明是第二常回的一句，配上 `=ret=`：

<Copy id="ts-ret" title="=ret= 展开后的退换说明" code="收到的东西有问题的话，拍张照片回这封邮件，我给你补寄或者退款，来回的运费都由我出。" />

缩写名字用英文字母加等号就好，不要把中文放进缩写本身。官方提醒过，缩写里有非英文字符时，要自己确认删得对不对，而英文字母和符号不会有这个麻烦。

## 做完怎么确认

打开 Mail 新建一封邮件，在正文里打 `=ship=`。你会看到这六个字符一闪就没了，换成整段回复；再在下面打 `=sig=`，三行签名一行不差地出来。

哪天你偏偏想打出 `=ship=` 这几个字本身，比如在给朋友讲这个办法，官方给了一个窍门：打到一半时按一下 ⇧空格（⇧ 是 Shift 键），再把它删掉，比如先打 `=sh`，按 ⇧空格，删掉，再打 `ip=`。⇧空格会打断这一串，缩写就不触发了。

## 卡住了？

<Q q="打了缩写，什么也没发生。">
先想想你是不是一口气打完的。中途停了好几秒、点了一下鼠标、按了带 ⌘ 或 ⌃（Control）的组合键、切到了别的 App，Keyboard Maestro 都会把这一串作废，从头算起。如果确实连着打完了还是不灵，多半是权限：输入字符串触发器和热键一样，要有<Term k="辅助功能权限" />才看得见你打的字。选 **Help ▸ Interactive Help**，它会替你查引擎有没有在跑、权限有没有给好，官方的说明在[排查页](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)。
</Q>
<Q q="在密码框里、在 Keyboard Maestro 自己的窗口里，缩写不灵。">
这是故意的。macOS 不让任何程序看你在密码框里打的字，所以缩写在密码框里一定不灵；Keyboard Maestro 自己弹出的窗口和编辑器本身，它也看不见或者用不好，官方建议在这些地方改用别的触发器。要是突然哪里都不灵了，可能是系统以为你一直待在密码框里（Secure Input），退出刚才要过密码的那个 App，或者重启一下，通常就好了，见[排查页的这一节](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode)。
</Q>
<Q q="在表格或文件列表里打了缩写，删掉了别的东西。">
「先删掉打出的字」其实是 Keyboard Maestro 替你按了几下删除键。在不是打字的地方，这几下删除可能删掉选中的东西，官方也专门提醒过。缩写只在写字的地方用，或者在那个宏里不勾删除。
</Q>
<Q q="贴出来的是上一次复制的东西。">
有的 App 处理粘贴慢，剪贴板已经换成了新的话，⌘V 却还没来得及生效，于是贴错；两条缩写紧挨着用时最容易遇到。官方在 [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) 里给了办法：要一起出来的话写进同一个动作，一次贴完；或者在两个粘贴动作之间加一个 **Pause**（暂停）。
</Q>

现在，你最常回的那几句话都有了一个以等号开头和结尾的名字。想在文字里放进今天的日期，接着看[一键插入今天的日期](/howto/insert-date/)。
