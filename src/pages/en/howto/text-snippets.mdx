If you run a small online shop, you probably answer the same few questions all day: thanks for your order, it ships within two working days, you'll get the tracking number by email. Twenty emails a day means typing that twenty times, and when you're rushing, half a sentence goes missing. When you finish this page, typing `=ship=` in Mail or anywhere else you can type will delete those six characters and put the whole reply in their place. Your signature and your returns note get abbreviations of their own.

If you haven't made an abbreviation before, start with [beginner lesson 2](/en/start/2-type-less/), which walks you through it from opening the editor. This page picks up from there: how to name them once you have several, why long text should be pasted, and where they simply won't work.

## Why the equals signs

A <Term k="输入字符串触发器" /> watches everything you type, and the moment the last few characters match its string, the macro runs. So if your abbreviation is an ordinary word, it'll fire when you didn't want it. The official example is using `em` for your email address, which then fires every time you type "them". Their advice is to give your abbreviations a consistent prefix or suffix, like `=em=`, something you'd never type by accident (see [Typed String trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String)).

<mark>Put an equals sign at each end, and an abbreviation only appears when you call it.</mark> Every example on this site uses that style: `=ship=`, `=sig=`, `=ret=`. Sticking to one style also makes them easy to remember. The moment you type an equals sign, you know you're calling an abbreviation.

## Start with the shipping reply

First, give your abbreviations a home. Click the + at the bottom of the macro group list on the left of the editor and make a new <Term k="宏组" /> called "Snippets". New macro groups are available in every app, which is exactly right here, since you might write replies in Mail one minute and in a web form the next.

In that group, make a new macro and call it "=ship= shipping reply" so you can spot it in the list later. Add a trigger, choose **Typed String**, and type `=ship=` after **This string is typed:**. Make sure the option underneath that deletes what you typed before the macro runs is ticked, so `=ship=` disappears before the reply shows up. Then add an **Insert Text by Pasting** action and write the reply in it:

<Copy id="ts-ship" title="What =ship= turns into" code="Thanks for your order! It'll ship within two working days, and I'll email you the tracking number as soon as it's on its way. If anything comes up, just reply to this email." />

There's no Save button in Keyboard Maestro. Your changes are saved a few seconds after you make them.

## Why paste instead of type

There are two everyday actions for inserting text. **Insert Text by Typing** types it key by key, just like you would. It's good for short text made of characters you can type with one or two keystrokes, up to about 30 or 40 characters. Anything longer gets slow, and it can't type emoji. **Insert Text by Pasting** puts the text on the clipboard and presses ⌘V (⌘ is the Command key) for you, so any length comes out at once, with any characters, and line breaks stay line breaks instead of acting like Return and pressing some button on a web page. The catch is that it replaces whatever was on your clipboard. The official [Insert Text](https://wiki.keyboardmaestro.com/action/Insert_Text) page compares the two.

Replies and signatures are often long and have several lines, so for abbreviations, **Insert Text by Pasting** is the one to reach for. Losing your clipboard isn't a big deal either: Keyboard Maestro's <Term k="剪贴板历史" /> keeps what you copied before, so you can get it back. See [full guide step 5](/en/guide/5-clipboard/).

## Two more: your signature and returns

Make two more macros in the same group, the same way. The signature has three lines, which shows off what pasting is good at. Every line break comes through:

<Copy id="ts-sig" title="What =sig= turns into" code={`Best,
Mia
Green Corner shop, replying Monday to Friday, 9:00 to 18:00`} />

The returns note is the second most common reply, so give it `=ret=`:

<Copy id="ts-ret" title="What =ret= turns into" code="If anything arrived damaged, reply with a photo and I'll send a replacement or a refund. I'll cover the postage both ways." />

Keep the abbreviations themselves to plain letters and symbols. The official page warns that if a trigger includes non-ASCII characters, you should check that the deletes work properly, and plain letters never have that problem.

## Check that it works

Open Mail, start a new message, and type `=ship=` in the body. You'll see the six characters vanish and the whole reply appear. Type `=sig=` underneath, and all three lines of your signature come out exactly as written.

If you ever need to type `=ship=` itself, say to show a friend this trick, the official page has a tip: halfway through, press ⇧Space (⇧ is the Shift key) and delete it. For example, type `=sh`, press ⇧Space, delete, then type `ip=`. ⇧Space breaks the sequence, so the abbreviation doesn't fire.

## Stuck?

<Q q="I typed the abbreviation and nothing happened.">
First, did you type it all in one go? Pausing for a few seconds, clicking the mouse, pressing a combination with ⌘ or ⌃ (Control), or switching apps all make Keyboard Maestro throw the sequence away and start counting again. If you did type it straight through, it's most likely permissions. Typed string triggers, like hot keys, need <Term k="辅助功能权限" /> to see what you type. Choose **Help ▸ Interactive Help** and it'll check whether the Engine is running and the permissions are in place. The official notes are on the [troubleshooting page](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key).
</Q>
<Q q="Abbreviations don't work in password fields or in Keyboard Maestro's own windows.">
That's on purpose. macOS doesn't let any app see what you type in a password field, so abbreviations never work there. In Keyboard Maestro's own pop-up windows the Engine can't see your typing either, and in the editor they don't work well, so the official advice is to use a different trigger in those places. If they suddenly stop working everywhere, the system may think you're still in a password field (Secure Input). Quitting the app that last asked for a password, or restarting, usually fixes it. See [this section of the troubleshooting page](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode).
</Q>
<Q q="I typed an abbreviation in a spreadsheet or a file list and it deleted something else.">
Deleting what you typed really means Keyboard Maestro presses Delete a few times for you. Outside a text field, those presses can delete whatever is selected, and the official page warns about exactly that. Only use abbreviations where you're writing text, or untick the delete option in that macro.
</Q>
<Q q="It pasted the thing I copied last time.">
Some apps are slow to handle a paste. The clipboard has already changed, but the ⌘V hasn't landed yet, so the wrong thing goes in. You're most likely to see it when you fire two abbreviations back to back. The official fix in [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) is to put text that belongs together in one action so it's pasted in one go, or to add a **Pause** between two paste actions.
</Q>

Now the things you write most each have a name that starts and ends with an equals sign. To put today's date in your text, carry on with [Insert today's date with one key](/en/howto/insert-date/).
