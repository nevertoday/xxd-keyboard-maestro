就職活動中は、1日に何社も応募メールを送ることになりますが、どのメールも最初の数行はほとんど同じです。毎回変わるのは、会社名と職種、そしてどこでその募集を知ったかだけ。前のメールをコピーして書き換えてもいいのですが、うっかり1か所直し忘れて、別の会社名をそのまま送ってしまうのが一番怖いところです。このページの手順を終えると、新しいメールで ⌃⌥⌘L（Control、Option、Command と L）を押すだけで小さなフォームが開いてこの3つを聞いてくれます。入力して Return キーを押せば、すべての名前が正しく入った丁寧な書き出しがカーソル位置に挿入されます。

ここまでのマクロは、最初から最後まで一気に動くものばかりでした。<mark>先にひとこと質問して、その答えを使って続きを動かせるようになると、「毎回少しずつ違う」作業もマクロに任せられるようになります。</mark>

## まずは小さなフォームで尋ねる

「応募メールの書き出し」という名前で新しい<Term k="宏" text="マクロ" />を作り、**Hot Key**（ホットキー）トリガーを追加して、⌃⌥⌘L を押します。1つ目のアクションは **Prompt for User Input**（ユーザー入力を求める）です。自分で設計したフォームを表示し、入力した内容を<Term k="变量" text="変数" />に保存してくれます（[Prompt for User Input アクション](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input)）。

フォームの一番上にあるタイトルには「応募メールの書き出し」と入れます。その下のプロンプト欄には、「今回はどこに送りますか？」のように自分宛てのひとことを書きます。さらにその下に変数が1行に1つずつ並び、左側が変数名、右側がデフォルト値です。次の3行を追加します。

- `Local Company`（デフォルト値は空のまま）
- `Local Role`（デフォルト値は空のまま）
- `Local Source`（デフォルト値に `求人サイト|友人の紹介|公式サイト` と入力）

先頭の `Local` は飾りではありません。Local で始まる変数はローカル変数になり、このマクロの実行中だけ存在して、終わると消えてくれます。そのため、Mac の中に変数がどんどん溜まる心配がありません。さらに、フォームのラベル表示では「Local」が自動で省かれるので、画面に見えるのは「Company」「Role」「Source」だけです（[Variables](https://wiki.keyboardmaestro.com/manual/Variables)、[Prompt for User Input アクション](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input)）。3行目のデフォルト値には縦棒 `|` が入っているので、Keyboard Maestro がこれをポップアップメニューにしてくれます。縦棒で区切ったそれぞれが選択肢になり、先頭のものが最初から選ばれた状態になります。

ボタンは最初から入っている2つだけで十分です。**OK** は Return キーに対応していて、フォームを閉じて次のアクションへ進みます。**Cancel**（キャンセル）は Esc キーまたは ⌘. に対応していて、変数に書き込まずにフォームを閉じ、そのままマクロを中止します。

## 回答を文章に差し込む

2つ目のアクションは **Insert Text by Pasting**（テキストを貼り付けて挿入）です。文章の中で `%Variable%変数名%` と書くと、さきほどの回答を取り出せます。下の文章を自分の言葉に合わせて書き換えてみてください。

<Copy id="ai-letter" title="Insert Text by Pasting に入れる文章" code={`はじめまして。

%Variable%Local Source%で、%Variable%Local Company%が%Variable%Local Role%を募集されていることを知りました。募集要項を拝見し、ここ数年取り組んできた仕事とよく合っていると感じたため、履歴書を添えてご連絡いたしました。一度お話しする機会をいただけますと幸いです。`} />

使うときは、メール本文の先頭にカーソルを置いてから ⌃⌥⌘L を押します。

<Callout type="ok">
「応募メールの書き出し」というタイトルの小さなウィンドウが開き、入力欄が2つとポップアップメニューが1つ表示されます。入力して Return キーを押すとウィンドウが閉じ、さきほど入力した3か所が差し込まれた書き出しがメールに貼り付けられます。
</Callout>

送信する前に一度は読み返しておきましょう。どこを差し替えるかはフォームが覚えていてくれますが、会社名が合っているか、文章のトーンが適切かを確かめるのはやはり自分の役目です。

## いくつかの中から1つ選ぶだけなら：Prompt With List

文字を入力するのではなく、候補から選ぶだけの「先に尋ねる」方法もあります。小さなネットショップを運営していると、お客様への返信は毎回ほぼ同じ文面になりがちです。発送しました、いつ頃届きます、返品・交換の案内など。**Prompt With List**（リストから選択）を使うと、Spotlight のようなウィンドウに選択肢の一覧が表示されます。数文字打って絞り込み、選んで Return キーを押すだけです（[Prompt With List アクション](https://wiki.keyboardmaestro.com/action/Prompt_With_List)）。

選択肢は1行に1つずつ、アクションの中にそのまま書けます。ウィンドウに表示するラベルと、選んだときに受け取る文章は別々にできます。1行を「受け取りたい文章、アンダースコア2つ、表示する短い言葉」の順に書くと、ウィンドウには後ろの短い言葉だけが表示され、選んだときには前の文章全体が返ってきます。たとえば次のようになります。

<Copy id="ai-list" title="Prompt With List に入れる選択肢" code={`ご注文の商品を本日発送いたしました。追跡番号は注文詳細からご確認いただけます。通常3〜5日ほどでお届けできる予定です。__発送済み
お荷物は現在配送中です。追跡情報は1日に1回ほど更新されます。何か変化がありましたらすぐにご連絡いたします。__配送中
もし届いた商品が合わなくても問題ありませんので、そのままご連絡ください。返品・交換の手順をお送りいたします。__返品・交換`} />

このアクションは別の新しいマクロに入れて専用のホットキーを割り当て、結果を `Local Reply` などの変数に保存したあと、**Insert Text by Pasting** を続けて `%Variable%Local Reply%` と書いておきます。Esc キーを押すとこのアクションは失敗扱いになって何も保存されず、初期設定では失敗の通知が出てマクロ全体も中止されます。そのため、返信をやめたいときはやはり Esc キーで戻れます。

## うまくいかないときは

<Q q="Cancel をクリックしたら、何も貼り付けられませんでした。">
それが本来の動きです。Cancel では変数に書き込まれず、マクロ全体が中止されます。「保存だけして貼り付けない」といった別の動きをする3つ目のボタンが欲しい場合は、フォームにボタンを追加します。押されたボタンの名前は `%PromptButton%` <Term k="令牌" text="トークン" />に入るので、続く **If Then Else**（もし〜なら／そうでなければ）で処理を分けられます。
</Q>
<Q q="%Variable%Local Company% という文字がそのまま貼り付けられてしまいます。">
フォームの変数名と文章の中に書いた変数名が、1文字も違わず一致しているか確認してみてください。`Local` の後ろのスペースも含まれます。一番確実なのは、手入力せず **Edit ▸ Insert Variable**（編集 ▸ 変数を挿入）メニューから変数を挿入する方法です（[Variables](https://wiki.keyboardmaestro.com/manual/Variables)）。
</Q>
<Q q="ポップアップメニューにしたいのに、入力欄になってしまいます。">
項目の種類が Automatic（自動）のときはデフォルト値から自動で判断されるため、縦棒が入っていないとメニューになりません。縦棒を入れていない場合や、はっきり指定しておきたい場合は、デフォルト値の右にあるメニューから Menu（メニュー）を選びます。
</Q>
<Q q="フォームは開いているのに、短縮入力が反応しません。">
公式 Wiki にもあるとおり、システム側の制限で、Keyboard Maestro Engine は自分自身のウィンドウ内で打たれたキーを読み取れません。そのため、このフォームの中では入力文字列トリガーが動きません。フォームにはそのまま手入力するか、別の場所でコピーしてから貼り付けてください。
</Q>

フォーム1つと変数をいくつか用意するだけで、毎回変わる部分だけ自分で入力し、残りはすべてマクロに任せられるようになります。変数と条件を組み合わせると、さらにいろいろなことができます。詳しくは[完全ガイドのステップ4](/ja/guide/4-variables/)で紹介しています。
