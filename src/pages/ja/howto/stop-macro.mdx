仕事で表計算を整理している人は、よくこんなマクロを作ります。セルを1つ下に動かして文字を打ち、また下に動かす、という操作を **Repeat**（繰り返し）で100回まわすものです。ところがある日、うっかり100を1000と打ち間違えたり、カーソルがそもそも表の中になかったりすると、関係ないウィンドウに何行も文字を打ち込み続け、こちらがどのキーを押してもお構いなしです。このページのやり方なら数秒で止められますし、最後のセクションまで読めば、あらかじめマクロに出口を作っておく方法もわかります。

まず、一番大事な操作だけ覚えておけば大丈夫です。あとは後から読んでも構いません。<mark>⌃⌥⇧ を押しながらメニューバーの Keyboard Maestro アイコンをクリックすれば、実行中のマクロはすべて止まります。</mark>

## 一番早い方法：すべて止める

メニューバーの右側にある Keyboard Maestro のアイコンが、<Term k="状态菜单" text="ステータスメニュー" />です。⌃⌥⇧（Control、Option、Shift の3つのキー）を押したまま、このアイコンをクリックすると、実行中のマクロがすべてキャンセルされます（[How do I ...?](https://wiki.keyboardmaestro.com/manual/How_do_I)）。実は公式ページでもキーの書き方が少しずつ違っていて、マニュアルの Menus ページでは ⌘ Command を含めた4つの修飾キーすべてを押すと書かれていますが、How do I ページでは ⌃⌥⇧ に加えて Command は押しても押さなくてもよいとあり、Troubleshooting ページでは ⌃⌥⇧ となっています。つまり3つのキーを押しておけば十分ですし、慌てて ⌘ まで一緒に押してしまっても問題ありません。

<Callout type="ok">
画面に文字が勝手に打ち込まれるのが止まり、マウスも自分の手に戻ってきます。
</Callout>

なお、マクロを止めても、すでに実行された処理までは元に戻りません。打ち込まれてしまった文字はウィンドウに残ったままなので、そのアプリ自身の「取り消す」で片付けてください。

## 1つだけ止める

いくつかのマクロが同時に動いていて、問題のあった1つだけを止めたいときは、いつも通りステータスメニューを開いて **Cancel**（キャンセル）にカーソルを合わせます。ここには今まさに動いているマクロがすべて並んでいるので、選んだものだけを止められます（[Menus](https://wiki.keyboardmaestro.com/manual/Menus)）。今どのマクロが動いているかを確認する役目も果たしてくれるので、止まったと思っていたマクロが実は裏で待機したままだった、というときにも気づけます。

## 動きを見ながら1つずつ止める

ステータスメニューから **Start Debugging**（デバッグを開始）を選ぶと、<Term k="调试器" text="デバッガ" />のウィンドウが開きます。ここには実行中のマクロすべてと、それぞれがいまどのアクションを実行しているかが表示され、右側にあるボタンから特定のマクロを **Cancel** できます（[Macro Debugger](https://wiki.keyboardmaestro.com/manual/Macro_Debugger)）。デバッガの中で **Pause New Macros**（新しいマクロを一時停止）にチェックを入れておくと、それ以降にトリガーされたマクロは最初の手順で一時停止して待ってくれます。そこから1アクションずつクリックして進められるので、暴走したマクロがどこでおかしくなっているのかを突き止めるのにぴったりです。なお、デバッガのウィンドウを閉じると、一時停止していたマクロはそのまま動き出してしまいます。止めたい場合は、先にキャンセルしてからウィンドウを閉じてください。

## どうしても止まらないとき

ここまでの方法でも止まらないときのために、公式 Wiki にはもう少し強力な手段も用意されています（[How do I ...?](https://wiki.keyboardmaestro.com/manual/How_do_I)）。

1つ目は、ステータスメニューから **Quit Keyboard Maestro Engine**（Keyboard Maestro Engine を終了）を選ぶ方法です。<Term k="引擎" text="エンジン" />が終了すれば、マクロは一切動かなくなります。ただ、次に Keyboard Maestro を開くとエンジンも一緒に起動するので、起動した瞬間にまたそのマクロが暴走してしまうようなら、次の「エンジンなしでエディタを開く」方法で修正します。

一番やっかいなのは、ログイン時に実行されるマクロです。Mac を起動するたびに飛び出してきて、直す間もなくまた動き出してしまいます。公式 Wiki の Troubleshooting ページにこのケースの対処手順が載っています（[Troubleshooting](https://wiki.keyboardmaestro.com/Troubleshooting#Run-Away_Login_Macros)）。

1. ⌃⌥⇧ を押しながらステータスメニューアイコンをクリックして、実行中のマクロをすべてキャンセルします。
2. ⌃⌥⇧⌘ の4つのキーすべてを押したまま、Dock の Keyboard Maestro をクリックするか、「アプリケーション」フォルダ内でダブルクリックします。これでエンジンが終了し、エンジンを起動せずにエディタだけが開きます。
3. エディタで該当のマクロを見つけ、トリガーを削除するか、マクロ自体をオフにします。
4. それでもうまくいかないときは、Mac をセーフモードで再起動します。これでエンジンを含むログイン項目が起動しなくなるので、あらためて ⌃⌥⇧⌘ を押しながら Keyboard Maestro を開き、そのマクロを修正します。

## あらかじめマクロに出口を作っておく

止め方がわかったら、次はあらかじめ備えておけます。Keyboard Maestro にはマクロをキャンセルするための<Term k="动作" text="アクション" />がいくつかあります：**Cancel All Macros**（すべてのマクロをキャンセル）、**Cancel All Other Macros**（ほかのすべてのマクロをキャンセル）、**Cancel This Macro**（このマクロをキャンセル）、**Cancel Just This Macro**（このマクロだけをキャンセル）です（[How do I ...?](https://wiki.keyboardmaestro.com/manual/How_do_I)）。一番シンプルな使い方は、緊急停止用のマクロを作っておくことです。新しいマクロを作り、**Hot Key**（ホットキー）トリガーとしてたとえば ⌃⌥⌘.（Control、Option、Command とピリオドキー）を設定し、アクションは **Cancel All Macros** を1つだけ入れます。やっていることはアイコンをクリックするのと変わりませんが、メニューバーを探す手間が省けます。

ちょっとした習慣でもトラブルを減らせます。ループを新しく作ったら、まずは3回のような小さい回数で試し、問題なく動くのを確かめてから100回に増やします。動きに自信が持てないマクロなら、先にデバッガを開いて **Pause New Macros** にチェックを入れ、1つずつ進めながら確認します。なお、マクロが途中で失敗したり一部の操作を飛ばしてしまったりする場合は、アプリの反応よりマクロの実行が速すぎるのが原因であることがほとんどで、これはまた別の問題です。少し待たせる方法については、公式 Wiki の [Timing Between Actions](https://wiki.keyboardmaestro.com/Troubleshooting#Timing_Between_Actions)（アクション間のタイミング）の項目で説明されています。

## うまくいかないときは

<Q q="メニューバーに Keyboard Maestro のアイコンが見つかりません。">
設定の **General**（一般）タブでステータスメニューを表示するかどうかや表示方法を設定できるので、オフになっていないか確認してみてください（[Preferences](https://wiki.keyboardmaestro.com/manual/Preferences)）。そもそもエンジンが起動していなければ、マクロも動いていません。また、公式の [Frequently Asked Questions](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions) ページによると、macOS Tahoe にはステータスメニューの配置に不具合があり、アイコンが別の位置にずれたり、隣のアイコンとの間に隙間ができたりすることがあるそうです。メニューバーのあたりをよく探してみてください。
</Q>
<Q q="キーを押しながらアイコンをクリックしたのに、普通にメニューが開いてマクロが止まりません。">
先に3つのキーを押して、そのまま押し続けた状態でクリックしてください。もしメニューが開いてしまっても問題ありません。一度手を離してメニューを閉じ、もう一度試してみてください。それでもうまくいかないときは、**Cancel** メニューからそのマクロを選ぶか、エンジンを終了してください。
</Q>
<Q q="一度は止まったのに、少し経つとまた勝手に動き出します。">
止めたのはその1回だけで、トリガー自体は残っています。決まった時刻や一定間隔、あるいはログイン時に実行される設定になっていると、そのタイミングが来ればまた動き出します。まずはそのマクロをオフにしてから直し、直ったらもう一度オンに戻してください。
</Q>

「⌃⌥⇧ を押しながらアイコンをクリックする」というこの一手さえ覚えておけば、少し長めの作業も安心してマクロに任せられます。マクロが思った通りに動かない理由や、どこで詰まっているかを調べる方法は、[マクロがうまく動かないとき](/ja/guide/6-debug/)にまとめています。
