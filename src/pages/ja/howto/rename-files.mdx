親の通院書類を管理していると、検査結果や処方箋、退院時の書類をスキャンして取り込むことになりますが、スキャナが付ける名前は Scan 1.pdf、Scan 2.pdf、Scan 3.pdf……といったものばかりです。何度か病院に通ううちに数十件もたまってしまい、半年後に前回の血液検査の結果を探そうとしても、1つずつ開いて確かめるしかありません。手作業で1つずつ名前を変えていると、10個目あたりで手が疲れてしまいます。マクロを使えば、Finder でファイルをまとめて選んで ⌃⌥⌘R（Control、Option、Command を押しながら R）を押すだけです。先頭に何を付けるか聞かれるので「父 11月受診」と入力すれば、選んだファイルがまとめて「父 11月受診 Scan 1.pdf」のような名前に変わります。

<mark>複数のファイル名をまとめて変えるのは、実は、選んだファイル1つひとつに同じことをするだけです。</mark>

<u>まずはコピーで試してください。</u>名前変更はディスク上の実際のファイルを書き換えるため、マクロに間違いがあると、選んだファイルすべてがまとめて間違った名前に変わってしまいます。Finder でフォルダを複製し、コピーした方で納得がいくまで試してから、本番のファイルに使うようにしましょう。

## For Each：1つずつ同じことを繰り返す

「1つずつ同じことを繰り返す」仕組みは、Keyboard Maestro では **For Each**（1つずつ処理する）と呼ばれています。処理したいもののリストを渡すと、その中から1つずつ取り出して<Term k="变量" text="変数" />に入れ、中にあるアクションを毎回実行してくれます（[For Each](https://wiki.keyboardmaestro.com/action/For_Each) を参照）。

そのリストはどこから持ってくるのでしょうか。For Each の中で **The Finder’s selection**（Finder で選択中の項目）を選べば、Finder で選択しているファイルがそのまま対象になります。公式ページによると、変数には各ファイルのフルパス、つまりディスクの一番上からファイル名までをつなげた長い文字列が入ります（[Working with the Finder Selection](https://wiki.keyboardmaestro.com/collection/Finders_Selection) を参照）。選択したファイルの名前をまとめて統一する使い方は、公式ページでも例の1つとして挙げられています。

パスが手に入ったら、あと必要なのは2つの手順だけです。パスから元のファイル名を取り出し、新しい名前に変更します。

## マクロを作る

「ファイル名の先頭に文字を付ける」という名前で新しいマクロを作ります。Finder だけで動くようにしたい場合は、**Available in these applications:**（指定したアプリでのみ利用可能）を Finder に設定したマクログループに入れておきます。トリガーには **Hot Key**（ホットキー）を選び、⌃⌥⌘R に設定します。続けて、次のアクションを追加していきます。

**手順1：先頭に付ける文字を聞く**。**Prompt for User Input**（ユーザー入力を求める）を追加し、タイトルに「ファイル名の先頭に文字を付ける」と入れます。ここに `Prefix` という名前の変数を1つ追加し、よく使う文字（「父 11月受診」など）を初期値として入れておきます。マクロがここまで進むと小さなウィンドウが開くので、必要に応じて文字を書き換えて **OK** をクリックします。**Cancel**（キャンセル）をクリックすれば、ファイルには1つも触れずにマクロ全体が止まります（[Prompt for User Input](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input) を参照）。

**手順2：1つずつ処理する**。**For Each** を追加して、変数に `FilePath` と入力し、コレクションの横にある「+」をクリックして **The Finder’s selection** を選びます。次の2つのアクションは、どちらもこの For Each の中に入れます。

**手順3：元の名前を取り出す**。For Each の中に **Split Path**（パスを分割）を追加し、分割するパスには次のように入力します。

<Copy id="rf-path" title="分割するパス" code="%Variable%FilePath%" />

このアクションは、パスを「入っているフォルダ」「ファイル名」「拡張子を除いた名前」「拡張子」といった要素に分け、それぞれ別の変数に保存できます（[Split Path](https://wiki.keyboardmaestro.com/action/Split_Path) を参照）。ここで必要なのは **File Name**（ファイル名）だけです。これを `FileName` という変数に入れます。拡張子も含めて `Scan 1.pdf` のような形になります。

**手順4：名前を変える**。続けて **File Actions**（ファイル操作）を追加し、**Rename**（名前変更）を選びます。対象のファイルには `%Variable%FilePath%`、新しい名前には次のように入力します。

<Copy id="rf-new" title="新しい名前" code="%Variable%Prefix% %Variable%FileName%" />

`%Variable%Prefix%` は<Term k="令牌" text="トークン" />です。マクロを実行すると、その変数の中身に置き換わります。公式ページによると、**Rename** の新しい名前に指定できるのはスラッシュを含まないファイル名だけなので、ファイルは元のフォルダに残ったまま名前だけが変わります（[File Actions](https://wiki.keyboardmaestro.com/action/File_Actions) を参照）。

## 動作を確認する

コピーしたフォルダでファイルを3つ選び、⌃⌥⌘R を押します。先頭に付ける文字を聞く小さなウィンドウが開くはずです。文字を入力して **OK** をクリックすると、Finder 上でその3つのファイル名の先頭に入力した文字が付き、元のファイル名と拡張子はそのまま残ります。選んでいないファイルの名前は変わりません。

新しい名前の欄には、ほかのトークンも入れられます。一番先頭に今日の日付を付けたい場合は、`%ICUDateTime%yyyy-MM-dd% %Variable%Prefix% %Variable%FileName%` と書きます。日付の書式を変える方法は、[キー1つで今日の日付を入力する](/ja/howto/insert-date/)を参照してください。

## うまくいかないときは

<Q q="⌃⌥⌘R を押してウィンドウは出たのに、ファイル名が1つも変わりません。">
For Each が取得するのは、その瞬間に Finder で選択されている項目です。まず、Finder で本当にファイルが選ばれているか確認してください。マクログループを Finder だけでアクティブになるよう設定している場合は、ホットキーを押すときに Finder が最前面にある必要もあります。そのうえで、手順3と手順4が For Each の後ろに並んでいるのではなく、中に入っているかも確認しましょう。
</Q>
<Q q="途中で止まってしまい、名前が変わったファイルと変わっていないファイルがあります。">
おそらくファイル名が重複しています。公式ページによると、変更後の名前と同じファイルがすでにそのフォルダにある場合、この処理はエラーになり、マクロはその場で止まります。どのファイルで止まったかを見て重複を解消してから、残りのファイルを選び直してもう一度実行してください。
</Q>
<Q q="一緒に選んでいたフォルダの名前まで変わってしまいました。">
**The Finder’s selection** は選択されているものをそのまま渡すため、**Rename** はファイルだけでなくフォルダにも効きます。名前を変えたいファイルだけを選ぶようにしてください。
</Q>
<Q q="ファイルが別のフォルダに移動してしまいました。">
おそらく **Move or Rename**（移動または名前変更）を選んでいて、新しい名前にスラッシュが入っていたため、そちらへ移動されたのだと思います。**Rename** に変えて、ファイル名だけを入力してください。
</Q>

For Each を使えるようになると、「1つずつ同じことをする」作業はどれも同じ仕組みで作れます。複数のファイルにまとめてタグを付けたり、1か所に移動したりするのも、中のアクションを差し替えるだけです。ファイルがフォルダに入った瞬間に自動で処理したい場合は、続けて[フォルダにファイルが入ったら自動で仕分ける](/ja/howto/watch-folder/)も見てみてください。
