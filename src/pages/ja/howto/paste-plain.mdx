ウェブページから引用文をコピーして授業のレポートに貼り付けると、そのページのフォントや文字サイズまでそのまま入ってしまうことがあります。文字がグレーになっていたり、リンクがついたままになっていたりして、5、6か所も貼り付けるころには、レポートがつぎはぎだらけになってしまいます。結局、1か所ずつ選択して手で元に戻すことになりがちで、レポートを書いたことのある学生ならたいてい経験があるはずです。これから紹介するマクロを作っておけば、⌃⌥⌘V（⌃ は Control、⌥ は Option、⌘ は Command）を押して貼り付けるだけで、文字だけが入るようになります。

<mark>先にクリップボードの書式を消してから貼り付ければ、文字だけが入ります。</mark>

## クリップボードには複数種類のデータが入っている

文章をコピーしたとき、クリップボードに入っているものは1つだけではありません。公式の [Troubleshooting](https://wiki.keyboardmaestro.com/Troubleshooting#Removing_Styles_Changes_The_Text) ページにある「Removing Styles Changes The Text」の項目にもはっきり書かれていますが、たった1回のコピーの中に、プレーンテキスト版、書式付き版、さらには画像まで一緒に入っていることがあり、これらは「flavor」と呼ばれています。貼り付けるとき、アプリはその中から一番都合よく使えるものを選びます。文書作成アプリなら当然ながら書式付き版を選ぶため、ウェブページのフォントまで一緒に入ってくるというわけです。

Keyboard Maestro の **Filter**（フィルタ）アクションには **Remove Styles**（書式を削除）というフィルタがあり、クリップボードをプレーンテキストに変えてくれます（詳しくは [Filters](https://wiki.keyboardmaestro.com/manual/Filters) に載っています）。書式付きのものがなくなれば、アプリが選べるのはプレーンテキストだけになります。

## マクロを作る

このマクロはどのアプリでも使いたいので、すべてのアプリで使えるマクログループに入れて、名前を「プレーンテキストで貼り付け」にします。トリガーには **Hot Key**（ホットキー）を選び、⌃⌥⌘V を押します。あとは次の2つのアクションを追加します。

1. **Filter**：対象に **System Clipboard**（システムクリップボード）、フィルタに **Remove Styles** を選び、結果をシステムクリップボードに戻します。
2. **Type a Keystroke**（キーを押す）：入力欄をクリックして ⌘V を押します。

2つ目の手順で、いつもの貼り付けのキーを代わりに押してもらいます。公式でも、Command キーを含むキー操作には **Type a Keystroke** を使うことが勧められています（詳しくは [Type Keystroke](https://wiki.keyboardmaestro.com/action/Type_a_Keystroke) に載っています）。

## できたか確認する

Safari で太字やリンクが含まれている文章を見つけてコピーします。次にテキストエディットを開いて新規書類を作り、自分で1行何か入力して Return キーを押し、続けて ⌃⌥⌘V を押します。太字もリンクも消えて、自分で打った行と同じフォントで文章が貼り付いているはずです。

1つ知っておきたいのは、このマクロはクリップボードの中身そのものをプレーンテキストに書き換えているという点です。そのため、この直後にいつもの ⌘V を押しても、次に別のものをコピーするまではプレーンテキストのまま貼り付きます。書式付きの元の内容に戻したいときは、<Term k="剪贴板历史" text="クリップボード履歴" />から探せます。詳しくは[完全ガイドのステップ5](/ja/guide/5-clipboard/)で説明しています。

**Filter** にはほかにもフィルタが用意されています。たとえば **Trim Whitespace**（空白を削除）は、文章の前後についた余分な空白を取り除いてくれます。1つ目の **Filter** の後ろにもう1つ **Filter** を足しておけば、引用文の前後につきがちな余計な空白も一緒に片付きます。

## うまくいかないときは

<Q q="書式を消したら、元の文章と少し変わってしまいました。たとえば箇条書きの先頭の黒丸が消えたり、逆に増えたりします。">
アプリによっては、クリップボードに入れるプレーンテキスト版と書式付き版で微妙に違う文字が入っていることがあり、**Remove Styles** はプレーンテキスト版のほうを読み込みます。公式の対処法は、**Filter** の前に **Set Clipboard to Text**（クリップボードにテキストを設定）アクションを1つ入れ、書式付きテキスト（styled text）を選んで内容に `%SystemClipboard%` と入力することです。こうすると Keyboard Maestro が両方の内容が一致したきれいなクリップボードを作り直してくれるので、そのあとで書式を消せばずれなくなります。詳しくは上で触れた「Removing Styles Changes The Text」の項目に載っています。
</Q>
<Q q="⌘V そのものをプレーンテキスト貼り付けにしたいのですが、ホットキーを ⌘V に設定してもいいですか？">
それはやめておきましょう。このマクロの2つ目の手順で自分自身が ⌘V を押すためです。アクティブなマクロのホットキーと同じキー操作をシミュレートすると、キーがそのまま入力されることもあれば、マクロ自身がもう一度動いてしまうこともあり、結果が予測できなくなると公式ページにもはっきり書かれています。別の組み合わせを選んでください。⌃⌥⌘V なら覚えやすいはずです。
</Q>
<Q q="それでも書式付きのまま貼り付いたり、前にコピーしたものが貼り付いたりします。">
アプリによっては、特にクロスプラットフォームのアプリでは、クリップボードの内容を独自にキャッシュしていて、Keyboard Maestro が今書き換えたことに気づかないことがあります。公式では、貼り付ける前に一度別のアプリへ切り替えてすぐ戻るなどして、そのアプリの目を覚まさせる方法が勧められています。詳しくは [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) に載っています。
</Q>

ホットキー1つとアクション2つだけで、引用文を貼り付けてもレポートがつぎはぎだらけになることはなくなります。よく貼り付ける文章をいくつか保管しておくなど、クリップボードにはほかにも便利な使い方がたくさんあります。まとめて[完全ガイドのステップ5](/ja/guide/5-clipboard/)で紹介しています。
