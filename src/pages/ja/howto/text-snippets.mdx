小さなネットショップを運営していると、毎日同じような返信を何度も送ることになります。ご注文ありがとうございます、2営業日以内に発送します、追跡番号はメールでお知らせします。1日に20通返信すれば20回打つことになり、急いでいると文の半分を書き漏らしてしまうこともあります。このページの手順を終えると、「メール」や文字を打てる場所ならどこでも `=ship=` と入力するだけで、その6文字が消えて返信の全文に置き換わります。署名や返品・交換の案内にも、それぞれ専用の短縮入力を作れます。

まだ短縮入力を一度も作ったことがない場合は、エディタを開くところから順を追って説明している[入門コースのレッスン2](/ja/start/2-type-less/)から始めてみてください。このページではその続きとして、短縮入力が増えてきたときの名前付けのコツ、長い文章を貼り付けで挿入すべき理由、そして仕組み上うまく動かない場面について説明します。

## 前後にイコールを付ける理由

<Term k="输入字符串触发器" text="入力文字列トリガー" />は普段の入力をずっと見ていて、直前に打った数文字が設定した文字列と一致した瞬間にマクロを実行します。そのため、短縮入力に普段使う単語を設定すると、意図しないタイミングで発動してしまいます。公式の例では、メールアドレス用に `em` を設定したところ、「them」と打つたびに発動してしまうケースが挙げられています。公式のアドバイスは、`=em=` のように普段の入力ではまず打たない決まった記号を先頭や末尾に付けることです（詳しくは [Typed String trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String) に書かれています）。

<mark>前後にイコールを1つずつ付けておけば、短縮入力は自分が呼び出したいときだけ出てきます。</mark>このサイトの例でも、`=ship=`、`=sig=`、`=ret=` のようにすべてこの形にそろえています。ルールを1つに決めておくと覚えるのも楽ですし、イコールを1つ打った瞬間に「今から短縮入力を呼び出す」と頭も切り替わります。

## まずは発送の返信から作ってみる

まずは短縮入力をまとめて入れておく場所を作ります。エディタ左側にあるマクログループ一覧の下の「+」をクリックして、「短縮入力」という新しい<Term k="宏组" text="マクログループ" />を作成します。新しく作ったマクログループは初期状態でどのアプリでも使えるので、この用途にぴったりです。返信は「メール」で書くこともあれば、Web 上のフォームで書くこともあるからです。

そのグループの中に新しいマクロを作り、あとから一覧で見つけやすいように名前を「=ship= 発送の返信」にします。次にトリガーを追加して **Typed String**（入力文字列）を選び、**This string is typed:**（この文字列が入力されたとき）の欄に `=ship=` と入力します。その下にある **Simulate 6 deletes before executing**（実行前に6文字分を削除）にチェックが入っていることも確認します（数字は短縮入力の文字数に合わせて変わります）。これで、返信が出る前に `=ship=` が自動で消えます。続いて **Insert Text by Pasting**（テキストを貼り付けて挿入）アクションを追加し、次の返信文を入力します。

<Copy id="ts-ship" title="=ship= で展開される返信" code="ご注文ありがとうございます！商品は2営業日以内に発送いたします。発送が完了しましたら、追跡番号をメールでお知らせします。ご不明な点がありましたら、このままメールでご返信ください。" />

Keyboard Maestro に保存ボタンはありません。編集してから数秒たつと自動で保存されます。

## タイピングではなく貼り付けを使う理由

文字を挿入するアクションには、よく使うものが2つあります。**Insert Text by Typing**（テキストをキー入力で挿入）は、自分で打つときと同じように1キーずつ入力します。キーボードを1〜2回押せば打てる文字で、長さも30〜40文字程度までの短い文章に向いています。それより長いと遅くなりますし、絵文字も打てません。一方、**Insert Text by Pasting** はいったん文字をクリップボードに入れ、代わりに ⌘V（⌘ は Command キー）を押してくれます。そのため、どれだけ長くても一瞬で入り、どんな文字でも扱えます。改行もそのまま改行として残るので、Web ページ上で Return キーを押した扱いになって意図せずボタンを押してしまうこともありません。デメリットは、もともとクリップボードに入っていた内容が上書きされることです。2つの違いは公式の [Insert Text](https://wiki.keyboardmaestro.com/action/Insert_Text) ページにまとめられています。

返信文や署名は長くて複数行になることが多いので、短縮入力には **Insert Text by Pasting** を選んでおくのが安心です。クリップボードの内容が上書きされても心配いりません。Keyboard Maestro の<Term k="剪贴板历史" text="クリップボード履歴" />に以前コピーした内容が残っているので、必要なときに呼び戻せます。詳しくは[完全ガイドのステップ5](/ja/guide/5-clipboard/)を見てみてください。

## あと2つ：署名と返品・交換の案内

同じマクログループに、同じ手順であと2つマクロを作ります。署名は3行あるので、貼り付けの良さがよく分かります。改行も欠けずにそのまま入ります。

<Copy id="ts-sig" title="=sig= で展開される署名" code={`よろしくお願いいたします。
ミア
グリーンコーナー（月〜金 9:00〜18:00 に返信いたします）`} />

返品・交換の案内は2番目によく送る返信なので、`=ret=` を割り当てます。

<Copy id="ts-ret" title="=ret= で展開される返品・交換の案内" code="届いた商品に破損などの不備がございましたら、写真を添えてこのメールにご返信ください。代替品の発送または返金にて対応いたします。往復の送料はこちらで負担いたします。" />

短縮入力の文字列そのものは、半角の英字と記号だけにしておきましょう。公式ページでも、トリガーに半角英字や記号以外の文字（非 ASCII 文字）を含める場合は削除が正しく動くか確認するよう注意しています。半角の英字と記号だけなら、そうした問題は起きません。

## ちゃんと動くか確かめる

「メール」を開いて新規メッセージを作成し、本文に `=ship=` と打ってみます。6文字が一瞬で消えて、返信の全文に置き換わるはずです。その下に `=sig=` と打つと、3行の署名が書いたとおりの形で出てきます。

友だちにこの方法を紹介するときなど、`=ship=` という文字そのものを打ちたい場面もあるかもしれません。そんなときのために公式ページで紹介されているコツがあります。途中で ⇧Space（⇧ は Shift キー）を一度押して、それを消すのです。たとえば、まず `=sh` と打ち、⇧Space を押して消してから `ip=` と続けます。⇧Space を挟むと連続入力が途切れるので、短縮入力は発動しません。

## うまくいかないときは

<Q q="短縮入力を打っても何も起きません。">
まずは、途中で止めずに一気に打てたか振り返ってみてください。数秒間手が止まったり、マウスをクリックしたり、⌘ や ⌃（Control）を含むキー操作をしたり、別のアプリに切り替えたりすると、Keyboard Maestro はそこまでの入力をリセットして最初から数え直します。ちゃんと連続して打ったのに反応しない場合は、権限が原因であることがほとんどです。入力文字列トリガーもホットキーと同じく、入力内容を読み取るために<Term k="辅助功能权限" text="アクセシビリティ権限" />が必要です。**Help ▸ Interactive Help**（対話型ヘルプ）を選び、「Something unexpected is happening」（予期しない動作が起きている）をクリックすると、明らかな問題があれば教えてくれます。公式の説明は [Troubleshooting](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key) ページにあります。
</Q>
<Q q="パスワード入力欄や、Keyboard Maestro 自身のウィンドウでは短縮入力が動きません。">
これは仕様です。macOS ではパスワード入力欄で打った文字をどのアプリにも見せない仕組みになっているため、そこでは短縮入力は動きません。Keyboard Maestro 自身のポップアップウィンドウでもエンジンは入力を読み取れず、エディタ内でもうまく動かないため、こうした場所では別のトリガーを使うよう公式でも案内されています。もし突然どのアプリでも動かなくなった場合は、macOS がまだパスワード入力欄にいると誤認している（Secure Input 状態のままになっている）可能性があります。直前にパスワード入力を求められたアプリを終了するか、再起動するとたいてい直ります。詳しくは [Troubleshooting の Secure Input Mode のセクション](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode)を見てみてください。
</Q>
<Q q="表計算ソフトやファイル一覧で短縮入力を打ったら、別のものが消えてしまいました。">
**Simulate 6 deletes before executing** は、文字どおり Keyboard Maestro が代わりに Delete キーを数回押す機能です。文字入力欄以外の場所で使うと、その数回の削除で選択中の項目が消えてしまうことがあり、公式ページでもまさにその点に注意するよう書かれています。短縮入力は文章を書く場所だけで使うか、そのマクロでこの項目のチェックを外しておいてください。
</Q>
<Q q="前回コピーしたものが貼り付けられてしまいます。">
アプリによっては貼り付けの処理が遅く、クリップボードの中身がすでに次に切り替わったあとで ⌘V が効いてしまい、別の内容が貼り付けられることがあります。2つの短縮入力を立て続けに使ったときに特に起きやすい現象です。公式の [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) では、まとめて出したい文章は1つのアクションに入れて一度に貼り付けるか、2つの貼り付けアクションの間に **Pause**（一時停止）を挟む方法が紹介されています。
</Q>

これで、よく書く文章それぞれに、前後をイコールで挟んだ名前が付きました。文章の中に今日の日付を入れたいときは、続けて[キー1つで今日の日付を入力する](/ja/howto/insert-date/)へ進んでみてください。
