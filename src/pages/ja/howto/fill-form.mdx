同じ案件サイトで仕事を探しているフリーランスなら、1日にいくつもの案件へ応募することもよくあります。しかも応募フォームは毎回ゼロから同じ項目を聞いてきます。名前、メールアドレス、電話番号、ポートフォリオのリンク。4つの項目を20回も打っていれば、電話番号を1桁打ち間違えてもおかしくありません。そうなるとクライアントが連絡を取れなくなってしまいます。このマクロを使えば、最初の欄をクリックして ⌃⌥⌘F（⌃ は Control、⌥ は Option、⌘ は Command）を押すだけで、4つの欄が一気に入力されます。カーソルは最後の欄で止まるので、内容を見直してから自分で送信をクリックできます。

<mark>フォームで次の欄へ移るのは Tab キーの役目なので、マクロも同じです。1つの欄を入力し、Tab を押し、次の欄を入力します。</mark>

## まずは自分でひと通り試してみる

マクロを作り始める前に、まずはそのフォームを開いて最初の欄をクリックし、Tab キーだけを1回ずつ押してカーソルがどこへ移動するか見てみます。たいていのフォームは上から下へ順に進みますが、サイトによっては途中にポップアップメニューや「同意する」のチェックボックスが挟まっていて、そこにも Tab が1回使われます。その順番をメモしておきます。マクロの仕事は、それをそのまま再生することだけです。

ここから分かる通り、1つのマクロで対応できるのは1つのフォームだけです。別のサイトになると項目の順番もたいてい違うので、そちら用に別のマクロを作ります。

## マクロを作る

まず「フォーム入力」という名前のマクログループを作り、設定で **Available in these applications:**（指定したアプリでのみ利用可能）を選んで Safari、または普段使っているブラウザを追加します。こうしておくと、⌃⌥⌘F はブラウザの中だけで効くようになり、ほかのアプリではそのまま自由に使えます。

そのグループの中に新しいマクロを作ります。トリガーに **Hot Key**（ホットキー）を選び、⌃⌥⌘F を押します。アクションは2つです。

1つ目は **Insert Text by Pasting**（テキストを貼り付けて挿入）で、ここに自分の名前を入れます。なぜ名前だけ別のアクションに分けるのでしょうか。もう一方のアクションである **Insert Text by Typing**（テキストをキー入力で挿入）は、キーボードのキーを1つずつ代わりに押す仕組みになっていて、公式ページによるとキーボードで1〜2回押すだけで打てる文字しか入力できないためです（[Insert Text by Typing](https://wiki.keyboardmaestro.com/action/Insert_Text_by_Typing) を参照）。たとえば漢字のように、その範囲に収まらない文字を含む名前はたくさんありますが、貼り付けならどんな文字でも問題なく入ります。

<Copy id="ff-name" title="1つ目のアクション：名前" code="佐藤花子" />

2つ目のアクションは **Insert Text by Typing** で、残りの項目をまとめて書き、項目と項目のあいだに `%Tab%` を入れます。`%Tab%` は<Term k="令牌" text="トークン" />で、マクロが動くときに本物の Tab キー入力に置き換わり、次の欄へカーソルが移ります。公式ページでもまさにこのやり方を勧めています。Tab や Return で欄を移動したいときは、キー入力を使うのが基本です。先頭に置いた `%Tab%` は、まず名前の欄から次の欄へ移るためのものです。

<Copy id="ff-rest" title="2つ目のアクション：残りの項目" code="%Tab%hanako.sato@example.com%Tab%000 1234 5678%Tab%https://example.com/hanako" />

サンプルのメールアドレス・電話番号・リンクは、自分のものに書き換えてください。2つ目のアクションはキー入力をするだけでクリップボードに触れないので、貼り付けの直後に続けても間違ったものが貼り付いてしまう問題は起きません。

<Callout type="warn">最後に Return を入れたり、マクロに送信ボタンを押させたりしないでください。入力が終わった状態でいったん止めておけば、まだ直せるうちに自分の目で確認できます。また、パスワードはマクロに入れないでください。公式の [Typed String trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String) のページでも、この方法でパスワード欄へ自動入力するのはセキュリティ上大きな問題だとしています。</Callout>

## うまく動くか確認する

そのサイトの応募フォームを開き、名前の欄をクリックして ⌃⌥⌘F を押します。まず名前が入り、続いてカーソルが1欄ずつ下へ移りながらメールアドレス、電話番号、リンクが順に入力され、リンクの欄で止まるはずです。それぞれの欄をひと通り確認してみてください。もしどこかの項目がずれた欄に入っていたら、「まずは自分でひと通り試してみる」に戻って、Tab の移動順が思っていた順番とどこで違っているか確かめます。

## うまくいかないときは

<Q q="文字は入りましたが、一部が抜けたり順番が入れ替わったりします。">
Web フォームの入力欄は、打たれた文字をリアルタイムでチェックしていることがよくあります。そこに Keyboard Maestro が速すぎるペースで打ち込むと、文字が抜けたり順番が乱れたりすることがあります。公式の対処法は、このマクロの先頭に **Set Action Delay**（アクション間隔を設定）アクションを追加して、入力のペースを少し落とすことです。全体の設定は変えず、このマクロだけに適用してください。詳しくは [Troubleshooting の文字が抜ける・順番が乱れる場合の項目](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_Typing_results_in_Characters_Missing_or_out_of_Order)を参照してください。
</Q>
<Q q="名前の欄に、さっきコピーした別の内容が貼り付いてしまいます。">
その時点ではクリップボードの中身はきちんと自分の名前に切り替わっています。アプリ側が古いクリップボードのコピーを独自に抱えていて、切り替わったことに気づいていないのが原因です。公式の [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) の項目によると、こうした現象はクロスプラットフォームのアプリでよく見られます。これに当たったときの一番簡単な逃げ道は、名前だけは自分で入力して、マクロは2つ目の欄から動かすことです。1つ目のアクションを削除し、2つ目のアクションの先頭にある `%Tab%` も消します。
</Q>
<Q q="途中から1欄ずつずれて入ってしまいます。">
その欄の手前に、見落としていたポップアップメニューやチェックボックス、ボタンなどがあって、そこで Tab が1回消費されている可能性が高いです。その箇所の `%Tab%` を1つ増やすか減らしてみてください。
</Q>
<Q q="メールアドレスの欄にアルファベットではなく変換候補が出てしまいます。">
**Insert Text by Typing** はキーを1つずつ押していく仕組みで、公式ページでも自分でタイピングするのと同じ扱いだと書かれています。そのため日本語や中国語などの入力メソッドがオンになっていると、メールアドレスのアルファベットがそのまま入力変換に吸い取られてしまいます。⌃⌥⌘F を押す前に、英数入力に切り替えておいてください。名前の欄は貼り付けで入るので、入力メソッドの影響は受けません。
</Q>
<Q q="⌃⌥⌘F を押しても何も起きません。">
まずブラウザが一番手前に来ているか確認してください。このマクログループはブラウザの中だけでアクティブになる設定なので、ほかのアプリで押しても反応しません。ブラウザが手前にあるのに動かないときは、エディタを開いて「フォーム入力」とこのマクロの両方にチェックが入ったままになっているか、またエンジンが動いているかを確認します。それでも動かない場合は、[完全ガイドのステップ6](/ja/guide/6-debug/)を見てみてください。
</Q>

1つ作っておけば、そのあとの応募からは毎回20文字あまり打つ手間が減り、打ち間違える機会も1つ減ります。どの案件に応募するかなど、毎回新しく書く項目については、マクロが先にひとこと尋ねてから入力することもできます。[作業の前に質問する](/ja/howto/ask-input/)を見てみてください。
