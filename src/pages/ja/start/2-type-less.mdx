1日に何度も打つ文章があります。保護者に返信する先生、お客さんに返事をするお店のオーナー、新しい問い合わせに答えるフリーランス。書いているのは、たいてい同じ数行です。「ご連絡ありがとうございます。メッセージを受け取りました。今週の金曜日までにお返事いたします。」毎回1文字ずつ打ち直したり、前回の文面を探し出してコピーしたりするのは、もう済ませたはずの作業をやり直していることになります。

このレッスンでは、文字を打てる場所ならどこでも `=reply=` の7文字を打つだけで、その文字が消えて、代わりに返信文がまるごと出てくるマクロを作ります。

## 打った文字を見張るトリガー

前のレッスンのマクロはキーを押して動かしました。今回は<Term k="输入字符串触发器" text="入力文字列トリガー" />という別のトリガーを使います。あらかじめ決めておいた文字列を打つと、マクロが動き出します。打った文字はいったん使っているアプリにそのまま入るので、ふつうはトリガーがまずその文字を消してから、アクションを実行します（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。

<mark><strong>ふだん間違って打つことのない文字列を打つと、その文字列を消して、保存しておいた文章に置き換えてくれます。</strong></mark>

この「ふだん間違って打つことのない」という点が大事です。トリガーはどのアプリで打ったキーもすべて見ているため、もし `reply` をトリガー文字列にしてしまうと、文章の中でその単語を打つたびにマクロが動いてしまいます。開発元は、文字列の前か後ろに決まった記号をつけることを勧めています。公式の例でも、「them」の中で反応してしまう `em` ではなく、`=em=` を使う形が紹介されています（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。このサイトの例もすべてこのルールにならい、前後にイコールをつけた `=reply=`、`=addr=`、`=sig=` を使います。

## マクロを作る

前のレッスンと同じように、エディタの左の列で **Global Macro Group**（すべてのアプリで有効なグループ）を選び、真ん中の列の下にある **+** をクリックして新しいマクロを作り、「よく使う返信」と名前をつけます。

1. 緑色の **+**（**New Trigger**：新しいトリガー）をクリックし、今回は **Typed String Trigger**（入力文字列トリガー）を選びます。
2. **This string is typed:**（この文字列が入力されたとき）の後ろにある入力欄に、`=reply=` と入力します。
3. その下にある **Simulate 7 deletes before executing**（実行前に7文字分を削除）にチェックが入っていることを確認します。これが、マクロが他の動きをする前に、いま打った7文字を自動で消してくれる設定です。
4. **New Action**（新しいアクション）をクリックし、**All Actions**（すべてのアクション）の一覧を下へスクロールして **Insert Text by Pasting**（テキストを貼り付けて挿入）を見つけ、ダブルクリックします。
5. 下の文章をこのアクションのテキスト欄にコピーし、文面や名前を自分のものに合わせて書き換えます。

<Copy id="l2-reply" code={"ご連絡ありがとうございます。メッセージを受け取りました。今週の金曜日までにお返事いたします。\n\nよろしくお願いいたします。\n佐藤"} />

準備できたら試してみましょう。テキストエディットを開いて新規書類を作り、`=reply=` と打ってみてください。

<Callout type="ok">
いま打った `=reply=` が消え、空行も含めて返信文がまるごと出てきます。
</Callout>

Keyboard Maestro のエディタの中では試さないでください。開発元によると、エディタでは少し変更するたびにすぐ保存が走るため、トリガーが途中で途切れてしまい、ほとんど動作しません（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。もう1つ覚えておきたいことがあります。<u>このトリガーは文字を入力できる場所だけで使い、Finder では決して使わないでください。</u>Finder で文字を打つとファイルが選択されてしまうため、マクロが代わりに押す削除キーによって、選択されたファイルがゴミ箱に移ってしまうことがあります（[公式 FAQ](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions#When_should_I_use_Typed_String_triggers)）。

## ついでに今日の日付も入れる

テキスト欄に入れられるのは固定の文章だけではありません。<Term k="令牌" text="トークン" />も使えます。パーセント記号で囲んだ名前を書いておくと、マクロが動くときに実際の値へ置き換わります。よく使うものの1つが `%LongDate%` で、今日の日付を省略しない長い形式に置き換えてくれます（[公式ページ](https://wiki.keyboardmaestro.com/token/LongDate)）。

たとえばテキスト欄の文章を次のように変えておくと、トリガーを打つたびにその日の日付が入ります。

<Copy id="l2-date" code={"このメモは%LongDate%にまとめました。何か質問があればいつでもお知らせください。"} />

日付が具体的にどう表示されるかは Mac の設定によって変わるので、一度打って確かめてみてください。トークンはほかにもたくさんありますが、必要なときに調べれば大丈夫です。最初のうちはこれ1つ知っていれば十分です。

## Pasting と Typing、どちらを選ぶ？

文字を挿入するアクションは2つあります。名前は1語しか違いませんが、仕組みはかなり異なります。

**Insert Text by Pasting** は、文章まるごとをいったんクリップボードに入れて、代わりに ⌘V を押してくれます。処理が速いので長い文章でも一瞬で出てきますし、絵文字も含めてどんな文字でも入れられます。ただし、クリップボードに元から入っていた内容が上書きされてしまい、マクロが終わっても元には戻らないのが難点です（[公式ページ](https://wiki.keyboardmaestro.com/action/Insert_Text_by_Pasting)）。

**Insert Text by Typing**（テキストを1文字ずつ打って挿入）は、本当に自分がキーボードを叩いているかのように、1キーずつ代わりに打ってくれます。そのため、カーソルがある場所の書式がそのまま引き継がれますし、文章の中の Return や Tab も、実際にそのキーを押したのと同じように働き、たとえばフォームの次の入力欄へ移ることができます。ただ、文字数が多いと時間がかかりますし、1〜2回のキー操作で打てる文字しか入力できないので、絵文字は使えません（[公式ページ](https://wiki.keyboardmaestro.com/action/Insert_Text_by_Typing)）。

つまり、選び方はシンプルです。そのまま打てる短いテキスト（開発元の目安は30〜40文字まで）や、Tab で次の入力欄へ移りたいときは Typing を使います。それ以外の、長い文章や特殊な文字を含むとき、またクリップボードが上書きされても構わないときは、Pasting を選びます（[公式 FAQ](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions#When_should_I_use_Insert_Text_by_Typing_instead_of_by_Pasting)）。

これでマクロが2つできました。キー1つでアプリを開くマクロと、数文字打つだけで文章まるごと出てくるマクロです。次のレッスンでは複数のアクションを並べて、毎朝の作業始めにいつもしているクリック操作を、キー1つでまとめて済ませられるようにします。

## うまくいかないときは

<Q q="=reply= と打っても、何も起きません。">

まず、ゆっくり打ちすぎていなかったか思い出してみてください。開発元によると、途中で数秒以上間が空いたり、マウスをクリックしたり、アプリを切り替えたり、⌘ や ⌃ を使ったキーの組み合わせを押したりすると、文字の数え直しになってしまいます（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。一気に打ち切って試してみてください。

次に、どこで打ったかも確認します。Keyboard Maestro のエディタの中や、Keyboard Maestro 自身が出しているウィンドウ、それにパスワード入力欄では動きません。代わりにテキストエディットやメモで試してみてください。

どちらにも当てはまらないときは、レッスン1と同じように **Help ▸ Interactive Help**（対話型ヘルプ）を選び、エンジンが動いているか、アクセシビリティ権限がオンになっているか、システムがパスワード入力中だと認識したままになっていないかをチェックしてもらいましょう（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)）。

</Q>
<Q q="別の入力ソースをオンにしたまま打つと、反応しないか、違う文字が消えてしまいます。">

トリガーを打つときは、ABC や U.S. のようなシンプルなキーボード配列に切り替えてください。そうすれば、その7文字がそのままアプリに届きます。開発元も、トリガーに通常の ASCII 文字以外を含める場合は、削除がうまくいくか自分で確かめるよう注意しています（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。そのため、トリガー自体は通常の英字と記号だけにしておきましょう。挿入する文章のほうは、どの言語で書いても構いません。

</Q>
<Q q="文章はまるごと出たのに、前に =reply= が残ったままです。">

トリガーの **Simulate 7 deletes before executing** にチェックが入っていないため、打った文字をマクロが消してくれませんでした。チェックを入れて、もう一度試してみてください。

</Q>
<Q q="貼り付けたあと、前にコピーしていた内容が消えてしまいました。">

それが **Insert Text by Pasting** の仕組みです。クリップボードを借りて貼り付けますが、終わったあとに元の内容は戻しません（[公式 FAQ](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions#Why_is_the_clipboard_not_restored_after_any_clipboard_action)）。文章が短くてシンプルな文字だけなら、**Insert Text by Typing** に変える手もあります。そうでなければ、返信を貼り付けてから別のものをコピーする習慣をつけておくと安心です。なお、Keyboard Maestro はコピーした内容を覚えています。取り戻し方は完全ガイド（英語）の[ステップ5](/en/guide/5-clipboard/)で紹介しています。

</Q>
<Q q="=reply= という文字そのものを打ちたいのですが。">

開発元が紹介している小技があります。打っている途中で Shift-Space（⇧ とスペースバー）を押してから Delete を押し、残りを打ち切ります。Shift-Space を押すと文字の数え直しになるため、そのときはトリガーが反応しません（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。

</Q>
<Q q="大文字で =REPLY= と打ったら、反応しませんでした。">

トリガーは初期設定で大文字と小文字を区別します。区別しない設定に変えることもできますが、登録したとおりの形で打つほうが手っ取り早いです（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Typed_String)）。

</Q>
