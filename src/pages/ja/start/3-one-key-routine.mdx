朝 Mac の前に座ると、だいたいこんな手順で手が動いているのではないでしょうか。まず「カレンダー」を開いて今日の予定を確認し、「メモ」を開いてやることリストを見ます。次に Safari を立ち上げて、講座のページや会社のシステム、お店の管理画面など、毎日チェックするページを開きます。それから Safari を画面の左側へ、「メモ」を右側へドラッグして並べ、ようやく作業スタートです。こうした7〜8回の操作を、毎日まったく同じようにくり返しています。

このレッスンでは、その一連の操作を1つのマクロにまとめます。⌃⌥⌘T（⌃ は Control、⌥ は Option、⌘ は Command、T は today の頭文字です）を1回押すだけで、最初から最後まで一気に片付けてくれます。

## 一連のアクションを、上から順に

前の2つのレッスンで作ったマクロは、どちらもアクションが1つだけでした。実は1つのマクロには複数のアクションをずらっと並べて入れられ、マクロが始まると Keyboard Maestro が上から順に1つずつ実行していきます（[公式 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)）。やることはシンプルで、毎日自分の手がたどっている手順を、そのまま順番に並べるだけです。

1か所だけ、少し気を配るポイントがあります。アクションによっては、実行したあと相手側の準備が本当に終わったのかを Keyboard Maestro が判断できません。たとえば Safari に Web ページを開かせたとき、ウィンドウが表示されるまでには少し間がありますが、Keyboard Maestro は待たずにすぐ次のアクションへ進んでしまいます（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Timing_Between_Actions)）。その次のアクションがまだ出ていないウィンドウを動かそうとすると、空振りになってしまいます。

<mark><strong>毎日クリックしている操作を順番に並べ、ウィンドウが表示されるのを待つ場所に Pause を入れます。</strong></mark>

## マクロを作る

**Global Macro Group**（すべてのアプリで有効なグループ）の中に、「朝のスタート」という名前で新しいマクロを作ります。**New Trigger**（新しいトリガー）をクリックして **Hot Key Trigger**（ホットキートリガー）を選び、⌃⌥⌘T を押します。続けて、次の6つのアクションをこの順番で追加します。いずれも **New Action**（新しいアクション）をクリックし、**All Actions**（すべてのアクション）から探してダブルクリックします：

1. **Activate a Specific Application**（特定のアプリを開いて前面に出す）。**Activate:** メニューで「カレンダー」を選びます。
2. もう1つ **Activate a Specific Application** を追加し、今度は「メモ」を選びます。
3. **Open a URL**（URL を開く）。**Open URL** 欄に毎日チェックするページのアドレスを `https://` から最後まで入力し、後ろの **with**（開くアプリ）で Safari を選びます。
4. **Pause**（一時停止）。Safari のウィンドウが表示されるのを待つため、1秒に設定します。
5. **Manipulate a Window**（ウィンドウを操作）。1つ目のメニューで **Move and Resize**（移動してサイズ変更）を選び、位置は **Left Column**（左半分）にします。対象のウィンドウは **the front window**（最前面のウィンドウ）、アプリは Safari を選びます。
6. もう1つ **Manipulate a Window** を追加し、同じく **Move and Resize** を選んで、今度は位置を **Right Column**（右半分）にします。ウィンドウは **the front window**、アプリは「メモ」を選びます。

アクションの順番がずれてしまったら、ドラッグして正しい位置に入れ替えられます。オプションの意味がわからないアクションがあれば、右上の歯車 **⚙** をクリックして **Help**（ヘルプ）を選ぶと、公式 Wiki のそのアクションの解説ページが開きます（[公式ページ](https://wiki.keyboardmaestro.com/manual/Macro_Actions)）。

## 試してみる

まず「カレンダー」、「メモ」、Safari をすべて終了してから、⌃⌥⌘T を押してみてください。

<Callout type="ok">
「カレンダー」と「メモ」が順番に開き、Safari で指定したページが表示されます。その1秒ほどあとに、Safari が画面の左半分、「メモ」が右半分に収まります。
</Callout>

ウィンドウが動かなかったり、片方だけしか配置されなかったりした場合は、おそらく待ち時間が足りていません。開発元によると普段は0.3秒で十分なことが多いそうですが、アプリをたくさん開いていてメモリに余裕がないときは数秒かかることもあります（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Timing_Between_Actions)）。**Pause** を2秒に変更して、もう一度試してみてください。

## 途中で止める

マクロは一度動き出すと、最後のアクションまでそのまま実行し続けます。意図しない動きを始めたときや、今すぐ止めたいときは、メニューバーにある Keyboard Maestro のアイコンから2通りの方法で止められます。このアイコンをクリックすると<Term k="状态菜单" />が開きます（[公式ページ](https://wiki.keyboardmaestro.com/manual/How_do_I#How_do_I_cancel_a_running_Macro)）：

- ⌃⌥⇧（Control、Option、Shift）を押し続けながらアイコンをクリックします。実行中のマクロがすべて止まります。
- もしくはアイコンをクリックして **Cancel**（キャンセル）を選び、実行中の一覧から止めたいマクロを選びます。今どのマクロが動いているかを確認したいときにも便利です。

覚えておくのは1つ目だけで十分です。いつかマクロが止まらなくなったら、この3つのキーを押しながらアイコンをクリックしてください。

## 動かないときの確認先

マクロがまったく反応しないときは、当てずっぽうで探す前に Keyboard Maestro 自身にチェックさせましょう。エディタを開いて **Help ▸ Interactive Help**（ヘルプ ▸ 対話式ヘルプ）を選び、「Something expected is not happening」（期待どおりに動かない）をクリックします（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Macros_Not_Firing_Triggered)）。

最初に確認してくれるのは全体の設定です。エンジンが動いているか、ログイン時に起動する設定になっているか、アクセシビリティ権限がオンになっているか、そしてシステムがパスワード入力中だと思ったまま引っかかっていないかを調べます。そこに問題がなければ、メニューから対象のマクロを選ばせ、所属するマクログループが有効か、マクロ自体が有効か、トリガーと有効なアクションが入っているかを順にチェックしてくれます。最後にホットキーを押すよう求められるので、押してみると実際にマクロがトリガーされたかどうかがわかります。

トリガーされたのに期待と違う動きをしたなら、原因はアクション側にあります。並べた順番やオプションの設定、待ち時間の不足などが考えられます。一方、トリガーすらされていないなら、原因はトリガーや権限、あるいはエンジン側にあります。こうして2つに切り分けられれば、どちらを探ればいいかがはっきりします。さらに詳しい調べ方は、完全ガイドの[ステップ6](/en/guide/6-debug/)（英語）で解説しています。

## 3つのレッスンが終わりました

ここまでで身につけた3つのことは、Keyboard Maestro にあるほぼすべてのマクロの基本形です。いつ始めるかを決めるトリガーがあり、何をするかを並べたアクションの列があり、必要な場所で少し待つ。キー1つでアプリを開く、数文字打つだけでまとまった文章を出す、キー1つで一連のルーティンを片付ける。これだけでも、毎日のくり返し作業はかなり減らせます。

あとの機能は、必要なときに調べるだけで大丈夫です。やりたいことが具体的に決まっているときは[ハウツー](/en/howto/)を、知らない言葉が出てきたら [Wiki](/en/wiki/) を見てみてください。マクログループや変数、クリップボードなどをしっかり理解したくなったら、完全ガイドの[ステップ0](/en/guide/0-what/)から順に読み進めるのがおすすめです（いずれも英語ページです）。開発元のおすすめどおり、一番の習得法は普段どおり Mac を使いながら「あ、また同じことをくり返しているな」と気づいた操作をマクロにしていくことです（[公式ページ](https://wiki.keyboardmaestro.com/manual/How_do_I#How_do_I_get_started)）。

## うまくいかないときは

<Q q="⌃⌥⌘T を押すとアプリは開くのに、ウィンドウが配置されません。">

待ち時間が足りていません。**Pause** を1秒から2秒に延ばし、それでも足りなければさらに増やしてみてください。アクションの順番も念のため確認しましょう。**Pause** は **Open a URL** の後ろ、2つの **Manipulate a Window** の前に置く必要があります。

</Q>
<Q q="ほかのウィンドウは配置されたのに、1つだけ動きませんでした。">

そのアプリは起動していたものの、ウィンドウが1枚も開いていなかった状態です。たとえば前回「メモ」を終了せずにウィンドウだけ閉じていた場合、**the front window** が空になってしまいます。そのアプリの **Activate a Specific Application** アクションで、初期ウィンドウを開き直す項目（「Reopen the app's initial windows」）にチェックを入れておけば、ウィンドウも一緒に開いてくれます（[公式ページ](https://wiki.keyboardmaestro.com/action/Activate_a_Specific_Application)）。

</Q>
<Q q="Web ページが開かず、画面の隅に失敗の通知が出ました。">

アドレスの書き方が正しくありません。**Open a URL** には、`https://` から始まり途中にスペースが入っていない、完全で正しい形式のアドレスが必要です（[公式ページ](https://wiki.keyboardmaestro.com/action/Open_a_URL)）。一番確実なのは、そのページを Safari で一度開き、アドレスバーからそのままコピーしてくる方法です。なお、このアクションが失敗してもマクロは通知を出すだけで、残りのアクションはそのまま続けて実行されます。

</Q>
<Q q="マクロが動き続けて止まりません。">

⌃⌥⇧ を押し続けながら、メニューバーの Keyboard Maestro アイコンをクリックしてください。それでも止まらない場合は、アイコンをクリックして **Quit Keyboard Maestro Engine**（Keyboard Maestro Engine を終了）を選び、エンジンごと終了するとすべてのマクロが止まります（[公式ページ](https://wiki.keyboardmaestro.com/manual/How_do_I#How_do_I_cancel_a_running_Macro)）。あとで Keyboard Maestro を開けば、エンジンも一緒にまた起動します。

</Q>
<Q q="メニューバーに Keyboard Maestro のアイコンが見つかりません。">

エンジンが動いていない可能性があります。Keyboard Maestro を一度開けば起動します。あるいは設定でアイコンが非表示になっているのかもしれません。**Keyboard Maestro ▸ Settings…**（設定）の **General**（一般）タブで、ステータスメニューを表示するかどうかや見た目を変更できます（[公式ページ](https://wiki.keyboardmaestro.com/manual/Preferences)）。

</Q>
<Q q="ホットキーを押しても何も起きません。">

上の「動かないときの確認先」の手順で **Help ▸ Interactive Help** を試してみてください。エンジンや権限に問題があると出た場合は、[レッスン1の「うまくいかないときは」](/ja/start/1-first-macro/)を見ながら確認してください。

</Q>
