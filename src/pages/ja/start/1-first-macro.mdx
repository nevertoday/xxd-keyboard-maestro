1日に何回くらい「メモ」を開きますか？ふと浮かんだことを書き留めようとして、マウスを Dock まで動かし、黄色いアイコンを探してクリックして、ウィンドウが開くのを待つ。1回はほんの数秒でも、1日に十何回も繰り返しますし、ウィンドウが出てくるまでのあいだに、せっかくの思いつきが消えてしまうこともあります。

このレッスンを終えるころには、⌃⌥⌘N を押すだけで「メモ」が最前面に出てくるようになります。起動していなければ、まず開いてから前に出してくれます。そのためにやることは3つだけです。Keyboard Maestro をインストールし、権限を許可して、バックグラウンドでずっと動くようにしておくこと。どれも最初の1回だけ済ませれば大丈夫です。

## マクロはひとことで言える：「〜したら、〜する」

Keyboard Maestro が代わりにこなしてくれる仕事は、どれも<Term k="宏" text="マクロ" />と呼びます。どんなに複雑なマクロでも、できているのは2つの部分だけです。「いつ始めるか」を決める<Term k="触发器" text="トリガー" />と、「始まったら何をするか」を決める<Term k="动作" text="アクション" />です。アクションは1つだけでも、いくつも並べたリストでもかまいません。並べた場合は上から順番に実行されます（[公式 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)）。

ですから、これから作るマクロもひとことで言い表せます。

<mark><strong>⌃⌥⌘N を押したら、「メモ」を前面に出す。</strong></mark>

⌃ は Control キー、⌥ は Option キー、⌘ は Command キーです。この3つをまとめて押しながら文字キーを押す組み合わせは、ほかのアプリではほとんど使われないので、ぶつかりにくくなります。「メモ」はあくまで例です。毎日いちばんよく開くのが「メール」でも「カレンダー」でも「テキストエディット」でも、そこに置き換えるだけで、あとの手順はまったく同じです。

## ダウンロードして、Finder で「アプリケーション」フォルダへ

Keyboard Maestro は公式サイトの [keyboardmaestro.com](https://www.keyboardmaestro.com/) からダウンロードします。Mac App Store には置いてありません。開発元の説明によると、ストアが求めるサンドボックス化の要件に合わせられないためです（[公式ページ](https://wiki.keyboardmaestro.com/manual/How_do_I)）。対応しているのは macOS 10.13 以降で、購入するまでは全機能が使える試用版として動作します（[公式ページ](https://wiki.keyboardmaestro.com/manual/Purchase)）。

ダウンロードしたファイルは zip ファイルです。ダブルクリックして展開すると、Keyboard Maestro のアプリが出てきます。次の手順は飛ばさないでください。<u>Finder を使って「アプリケーション」フォルダにドラッグし、そこから開きます。</u>macOS には App Translocation というセキュリティ機能があり、ダウンロードしたアプリを移動しないまま開くと、システムがランダムな場所から起動してしまいます。するとログイン時の自動起動が効かなくなり、アップデートも失敗してしまいます。Finder で移動すればこの制限は解除されます。ほかの方法で移動しても解除されません（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#App_Translocation_Security)）。

## 開くと、実は2つのプログラムが動き出します

Keyboard Maestro を開いたときに表示されるウィンドウが<Term k="编辑器" text="エディタ" />です。マクロを作ったり編集したりするのは、このウィンドウで行います。同時にもうひとつのプログラム、**Keyboard Maestro Engine** も裏で静かに起動します。こちらが<Term k="引擎" text="エンジン" />です。エンジンにはウィンドウがなく、ずっとバックグラウンドで待機しています。ホットキーの入力を待ち受けたり、マクロを実行したりしているのはこのエンジンです（[公式ページ](https://wiki.keyboardmaestro.com/manual/How_do_I)）。

この役割分担を覚えておくと、この先いろんなことがすんなり理解できます。編集が終わったらエディタは終了してもかまいません。実際に働いているのはエンジンなので、マクロはそのまま動き続けます。逆に、エンジンが動いていなければ、どのマクロも一切反応しません。

初めて開いたときは、**Start Tutorial**（チュートリアルを開始）というボタンの付いたウェルカムウィンドウが表示されます。Keyboard Maestro に最初から入っている公式のチュートリアルです。このレッスンとほぼ同じ内容を扱っているので、あとから見ても大丈夫です。

## 権限を許可する

Keyboard Maestro は代わりにキーを押し、メニューを選び、ウィンドウを動かします。Mac の操作を肩代わりする仕組みなので、macOS はきちんと本人の許可を求めます。それが<Term k="辅助功能权限" text="アクセシビリティ権限" />です。この権限がないと、Keyboard Maestro はキーボード入力を読み取れないため、ホットキーを設定することすらできません（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)）。

初めて起動したときに Keyboard Maestro から案内が出ますし、足りない設定があるあいだは、エディタウィンドウの右下に小さな黄色い三角アイコンが表示されます。そこをクリックして案内に従ってもいいですし、自分で設定を開くこともできます。

1. **システム設定 ▸ プライバシーとセキュリティ ▸ アクセシビリティ**を開きます。旧バージョンの macOS では、**システム環境設定**の「セキュリティとプライバシー ▸ プライバシー」にあります。
2. 一覧から **Keyboard Maestro Engine** を探してオンにします。**Keyboard Maestro** も一覧にあれば、こちらもあわせてオンにします。途中で macOS からログインパスワードの入力を求められることがあります。

<Callout type="ok">
Keyboard Maestro に戻ると、右下の黄色い三角が消えています。まだ残っている場合は、クリックして何が足りないか見てみてください。
</Callout>

この先、あるアプリを初めて操作するときや、特定のシステム機能を初めて使うときにも、macOS がもう一度確認ダイアログを出してくることがあります。これは正常な動作です（[公式 FAQ](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions)）。許可を求めているのが Keyboard Maestro であることを確かめてから、許可してください。

## ログイン時からエンジンが動くようにする

エンジンはログアウトやシステム終了をするまでずっと動き続けますが、次に Mac を起動したときは、設定しておかない限り勝手には戻ってきません。開発元もこの設定をオンにしておくことを勧めています（[公式 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)）。

1. Keyboard Maestro で **Keyboard Maestro ▸ Settings…**（設定）を選びます。旧バージョンの macOS では Preferences… と表示されます。
2. **General**（一般）タブで、**Launch Engine at Login**（ログイン時にエンジンを起動）にチェックを入れます。

これで Mac を起動するたびにエンジンがバックグラウンドで待機するようになり、ログインした直後からマクロが使えるようになります。

## 最初のマクロを作る

エディタのウィンドウは3つの欄に分かれています。いちばん左が<Term k="宏组" text="マクログループ" />で、マクロをまとめるフォルダのようなものです。真ん中には、選んだグループの中にあるマクロが並びます。いちばん右には、いま選んでいるマクロの中身が表示されます。

1. 左の欄で **Global Macro Group**（すべてのアプリで有効なグループ）を選びます。このグループに入れたマクロは、どのアプリを使っていても動きます。
2. 真ん中の欄の下にある **+** をクリックして、新しいマクロを追加します。「メモを開く」のような名前を付けます。
3. 右の欄で緑色の **+**（**New Trigger**：新しいトリガー）をクリックし、**Hot Key Trigger**（ホットキートリガー）を選びます。空の入力枠が出るので、そこをクリックしてから ⌃⌥⌘N を押します。押したキーの組み合わせがそのまま枠に表示されます。
4. **New Action**（新しいアクション）をクリックします。ウィンドウの左側にアクションの長い一覧が出るので、**All Actions**（すべてのアクション）カテゴリを選びます。アルファベット順に並んでいるため、**Activate a Specific Application**（指定したアプリを開いて前面に出す）は先頭のほうに見つかります。それをダブルクリックします。
5. 追加されたアクションの **Activate:** メニューで「メモ」を選びます。

Keyboard Maestro には「保存」ボタンがありません。何か変更すると、数秒後に自動で保存されます（[公式 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)）。作ったそばからそのまま動くので、何かを再起動する必要もありません。

## 試してみる

デスクトップをクリックするか、ほかのアプリに切り替えてから、⌃⌥⌘N を押してみてください。

<Callout type="ok">
「メモ」が最前面に飛び出してきます。⌘Q で「メモ」を終了してからもう一度押すと、今度は「メモ」が起動します。
</Callout>

もうひとつ小さな実験をしてみましょう。**Keyboard Maestro ▸ Quit Keyboard Maestro**（Keyboard Maestro を終了）を選んでエディタを閉じ、もう一度 ⌃⌥⌘N を押してみます。「メモ」は変わらず出てきます。ホットキーを待ち受けて動いているのは、ずっとバックグラウンドにいるエンジンだからです。

ここまでで、Keyboard Maestro をインストールし、権限を許可し、ログイン時にエンジンが起動するように設定して、最初のマクロまで作り終えました。ホットキー1つにアクション1つです。次のレッスンでは別の種類のトリガーを使って、数文字打つだけで文章がまるごと出てくるようにします。

<Callout type="tip" title="3つのレッスンで十分です">
レッスン2では、数文字打つだけで文章がまるごと出るマクロを作ります。レッスン3では、仕事を始めるときの決まった手順を1つのマクロにまとめ、途中で止める方法や、動かなくなったときに見る場所も覚えます。この3つのレッスンを終えれば、自分でマクロを作れるようになります。サイト内のそのほかのページは、必要なときに調べるだけで大丈夫です。
</Callout>

## うまくいかないときは

<Q q="⌃⌥⌘N を押しても何も起きません。">

いちばん早いのは、Keyboard Maestro 自身に診断してもらうことです。エディタを開いて **Help ▸ Interactive Help**（対話型ヘルプ）を選び、「Something expected is not happening」（起きるはずのことが起きない）をクリックします。するとエンジンが動いているか、権限がオンになっているかを順に確認し、そのあと対象のマクロを選ばせて、マクログループとマクロ本体が有効か、トリガーとアクションが入っているかを調べてくれます（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Macros_Not_Firing_Triggered)）。指摘された箇所を直せば解決します。

</Q>
<Q q="ホットキーの入力枠をクリックしてキーを押しても、何も表示されません。">

ほとんどの場合、アクセシビリティ権限が原因です。許可が足りないと、Keyboard Maestro からキーボードが見えません（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)）。上の「権限を許可する」をもう一度見直してみてください。権限がオンになっているのに直らない場合は、パスワードを入力中だとシステムが誤認したまま固まっている可能性があります。次の項目を見てみてください。

</Q>
<Q q="システム設定ではオンになっているのに、Keyboard Maestro には権限がないと表示されます。">

開発元もはっきり書いていますが、macOS の権限システムは Mojave 以降ずっと不具合を抱えています。オンになっているのに反映されなかったり、実際には許可されていないのに、システムが Keyboard Maestro に対して権限ありと伝えてしまったりするのです（[公式ページ](https://wiki.keyboardmaestro.com/manual/Troubleshooting)）。公式の対処法を上から順に試してみてください。まず**アクセシビリティ**で **Keyboard Maestro Engine** を一度オフにしてから再びオンにします。次に Keyboard Maestro とエンジンの両方を終了して開き直します。それでもだめなら Mac を再起動します。

もうひとつ考えられる原因があります。どこかのアプリが、ずっとパスワードを入力している状態だとシステムに思い込ませてしまうケースです。こうなると、どのプログラムからもキーボードが見えなくなります。これは Secure Input と呼ばれる状態です。原因のアプリを終了するか Mac を再起動すると元に戻ります。これが原因かどうかは、**Help ▸ Interactive Help** で「Something unexpected is happening」（意図しないことが起きる）を選ぶと教えてくれます（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode)）。

</Q>
<Q q="エディタに App Translocation の警告が出る、あるいは再起動後にマクロが動かなくなりました。">

たいていはアプリがまだ「ダウンロード」フォルダに残っているか、Finder 以外の方法で「アプリケーション」フォルダへ移したことが原因です。いったん Keyboard Maestro を終了し、Finder で「アプリケーション」フォルダへドラッグしてから、そこから開き直してください（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#App_Translocation_Security)）。そのあと、**Launch Engine at Login** にチェックが入っているかも確認しておいてください。

</Q>
<Q q="今日 Mac を起動したら、ホットキーがどれも効かなくなっていました。">

ログイン時にエンジンが起動していない状態です。Keyboard Maestro を1回開けば、エンジンも一緒に起動します。そのうえで **Keyboard Maestro ▸ Settings…** の **General** タブを開き、**Launch Engine at Login** にチェックを入れておけば、今後は気にしなくて済みます（[公式ページ](https://wiki.keyboardmaestro.com/Troubleshooting#Macros_Not_Firing_After_You_Login)）。

</Q>
<Q q="ホットキーを押したら「メモ」は開いたのですが、別のアプリも一緒に反応してしまいました。">

ほかのアプリも、システム全体で効くホットキーとして ⌃⌥⌘N を登録しているためです。開発元の説明によると、2つのプログラムが同じホットキーを登録している場合、自分のマクロと相手のコマンドの両方が同時に実行されます（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Hot_Key)）。トリガーの入力枠をクリックして、⌃⌥⌘ と別の文字にするなど、違う組み合わせを選び直してください。

</Q>
<Q q="ホットキーを押したら、マクロを選ぶための小さな一覧が出てきました。">

同じホットキーを2つのマクロに割り当てているためです。どちらを実行したいのか Keyboard Maestro が判断できず、両方を一覧で出して選ばせてくれています（[公式ページ](https://wiki.keyboardmaestro.com/trigger/Hot_Key)）。どちらか一方のホットキーを別のものに変えれば、一覧は出なくなります。

</Q>
