オンラインで求人の応募フォームを入力しているとします。履歴書から電話番号をコピーして貼り付け、次にメールアドレスをコピーして貼り付け、さらに何度も書き直した自己紹介文をコピーします。フォームに戻ってからポートフォリオのリンクを入れ忘れたことに気づきますが、前にコピーしたリンクは新しいコピーに上書きされてもう残っていません。Mac のクリップボードは一度に1つしか入らないため、何かをコピーするたびに前の内容が押し出されてしまうのです。

<mark><strong>Keyboard Maestro を入れておけば、コピーした内容はちゃんと残ります。直近数百回分のコピーを覚えていてくれるうえ、よく使う数件には名前を付けてずっと保管しておけます。</strong></mark>

このステップでは、3つの機能を扱います。前にさかのぼれる<Term k="剪贴板历史" text="クリップボード履歴" />、長く保管しておける<Term k="命名剪贴板" text="名前付きクリップボード" />、そして貼り付ける前にテキストを整えられるフィルターです。どれも自分でマクロを作る必要はなく、Keyboard Maestro を入れた瞬間から使えます。もちろん、それぞれに対応するアクションもあるので、自分のマクロに組み込むこともできます。

## クリップボード履歴：キーひと押しで前に戻る

どのアプリでコピーしても、そのたびに<Term k="引擎" text="エンジン" />がクリップボードの中身を控えとして保存します。初期設定では最大200件まで記憶され、件数は設定から変更できます（[公式 Wiki](https://wiki.keyboardmaestro.com/manual/Clipboard_History_Switcher)）。履歴をさかのぼるには、**Clipboard History Switcher**（クリップボード履歴の切り替え）を開きます。これは Keyboard Maestro に最初から入っているマクロで、**Switcher Group**（切り替え用グループ）というマクログループの中にあり、初期設定のホットキーは ⌃⇧⌘V（Control-Shift-Command-V）です。

<Callout type="ok">
⌃⇧⌘V を押すと一覧が表示されます。一番上がたった今コピーした内容で、下へ行くほど過去のコピーになります。
</Callout>

使いたい項目が見つかったら、ダブルクリックするか Return キーを押すか、書類にドラッグするだけで、文字を入力していた場所に貼り付けられます。覚えておくと便利な使い分けもいくつかあります。

- ⇧ Shift を押しながら Return キーを押すかダブルクリックすると、元のフォントや色を取り除いたプレーンテキストとして貼り付けます。
- ⌥ Option を押しながら同じ操作をすると、すぐには貼り付けず、システムクリップボードに戻すだけにとどめます。
- ⌘ と数字キーを押すと、対応する番号の項目を直接貼り付けます。
- ウィンドウ上部の検索欄に覚えている言葉を少し入れれば目的の項目が見つかり、画像だけやお気に入りだけに絞り込むこともできます。
- よく使う項目をお気に入りに登録しておくと、古い履歴として押し出されることがなくなります。
- 複数の項目を選んでまとめて1つにして貼り付けられます。項目の間に何を挟むかは、歯車メニューから選びます。

そのため、冒頭の応募者も電話番号・メールアドレス・リンク・自己紹介文をまとめてコピーしておき、フォームに戻ってから ⌃⇧⌘V で1件ずつ貼り付けられます。

ウィンドウを開かずに使う方法もあります。メニューバーにある Keyboard Maestro の<Term k="状态菜单" text="ステータスメニュー" />を開くと、**Paste**（貼り付け）メニューに直近30件のテキストが並んでいるので、選ぶだけで貼り付けられます（[公式 Wiki](https://wiki.keyboardmaestro.com/Status_Menu)）。

## 記録しないものと、残る期間

クリップボード履歴は何でも記録するため、あらかじめ知っておきたい点がいくつかあります（[公式 Wiki](https://wiki.keyboardmaestro.com/manual/Clipboard_History_Switcher#Other_Operations)）。

- <strong>パスワードらしい内容</strong>は一覧上で伏せられ、10番目まで押し下げられると自動で削除されます。ディスクにも一切保存されません。中身を確認したいときは、⌥ Option を押しながらクリックします。この動作は、設定の **General**（一般）にある **Detect (and Conceal) Possible Passwords**（パスワードらしい内容を検出して隠す）で管理されています。
- <strong>再起動後も残るかどうか</strong>は、**General** の **Save Clipboard History Between Launches**（再起動後もクリップボード履歴を保持）の設定次第です。これがオフだと、エンジンが終了するたびに履歴が空になります。Mac を再起動したときもエンジンは終了します（[公式 Wiki](https://wiki.keyboardmaestro.com/Clipboards#Options)）。
- <strong>記録してほしくないアプリ</strong>（たとえば他の人の個人情報を管理しているアプリなど）は、設定の **Excluded**（除外）にあるクリップボード履歴の除外リストに追加できます。除外したアプリが手前に表示されている間、Keyboard Maestro はクリップボードを自動記録しません（[公式 Wiki](https://wiki.keyboardmaestro.com/manual/Preferences#Excluded_Preferences)）。

設定画面は、メニューバーの **Keyboard Maestro ▸ Settings**（設定。旧バージョンの macOS では Preferences）から開きます。

もう1つ、自分で作るマクロに関わる注意点があります。**Insert Text by Pasting**（テキストを貼り付けて挿入）や **Copy to Named Clipboard**（名前付きクリップボードにコピー）など、多くのアクションはシステムクリップボード経由で動くため、<u>実行すると元のシステムクリップボードの内容が上書きされます</u>（[公式 Wiki](https://wiki.keyboardmaestro.com/Clipboards#Actions_That_Use_The_Clipboard)）。こうしたマクロを動かした直後に ⌘V を押すと、マクロがさっき貼り付けた文字が出てくることがあります。ただ、自分でコピーした内容も1〜2件前の履歴に残っているので、さかのぼれば取り出せます。

## 名前付きクリップボード：名前を付けて長期保管する

クリップボード履歴は流れ続ける川のようなもので、新しいコピーが入るたびに古いものが下へ押し流されます。お店のロゴと電話番号が入ったメール署名、よく貼り付ける画像、書式を整えた講座案内など、ずっと同じ場所に置いておきたいものもあります。そういうときに使うのが名前付きクリップボードです。

名前付きクリップボードは厳密にはクリップボードというより、クリップボードの中身を保存しておく小さなファイルに近い仕組みです。入れた内容は再起動してもそのまま残り、自分で書き換えるか削除するまで消えません。<Term k="变量" text="変数" />との一番大きな違いは、書式付きテキストや画像も保存できる点です。変数に入れられるのはプレーンテキストだけです（[公式 Wiki](https://wiki.keyboardmaestro.com/Clipboards#Named_Clipboards)）。

作り方は簡単です。設定の **Clipboards**（クリップボード）を開いて + ボタンをクリックし、右上の1行入力欄に名前を付けたら、その下の大きな欄に中身を貼り付けます。プレーンテキストでも書式付きテキストでも、画像でも入れられます。

使い方は2通りあります。

- **Named Clipboard Switcher**（名前付きクリップボードの切り替え）は、名前付きクリップボードの一覧を表示するウィンドウです。Keyboard Maestro は **Switcher Group** の中にこのウィンドウを開くマクロを3つ用意しており、初期設定のホットキーは ⇧⌘X、⇧⌘C、⇧⌘V です。それぞれ「切り取って入れる」「コピーして入れる」「取り出して貼り付ける」に対応しています（[公式 Wiki](https://wiki.keyboardmaestro.com/manual/Named_Clipboard_Switcher)）。ホットキーを押すと Keyboard Maestro 側が先に受け取るため、普段使っているアプリで ⇧⌘V を別の用途に使っているなら、このマクロのホットキーを別のキーに変えておきましょう。
- マクロの中で使う場合は、**Copy to Named Clipboard** で選択中の内容を名前付きクリップボードにコピーし、**Paste from Named Clipboard**（名前付きクリップボードから貼り付け）で貼り付けます。これらのアクションは必ずシステムクリップボードを経由するため、実行後はシステムクリップボードにも同じ内容が入ります（[公式 Wiki](https://wiki.keyboardmaestro.com/action/Copy_to_Named_Clipboard)）。テキスト入力欄では、`%NamedClipboard%name%` トークンを使って名前付きクリップボードのテキストを文章の中に差し込めます。

<Callout type="warn">
名前付きクリップボードの一覧には、最初から **Default Clipboard**（デフォルトのクリップボード）という項目が入っています。公式 Wiki でもわざわざ注意書きがあるのですが、これはごく普通の名前付きクリップボードの1つで、「Default」は最初から用意されているという意味にすぎません。<u>Mac のシステムクリップボードではないのです。</u>
</Callout>

## 貼り付ける前に整える

Web ページから段落をコピーしてメールに貼り付けると、ページ側のフォントや色まで一緒についてきます。表計算ソフトから名前の列をコピーすると、余分な空白が混ざっていたり、並び順がバラバラだったりします。こうしたひと手間は、貼り付ける前にまとめて片づけられます。

一番手軽なのは、クリップボード履歴の中で処理する方法です。項目を選んで歯車ボタンをクリックするか右クリックすると、プレーンテキストへの変換など、よく使う加工メニューが並んでいます。選ぶと加工済みの新しい項目が作られるので、あとはそれを貼り付けるだけです（[公式 Wiki](https://wiki.keyboardmaestro.com/manual/Clipboard_History_Switcher#Gear_Context_Menu)）。

マクロの中で自動処理したいときは、**Filter**（フィルター）アクションを使います。まず対象（システムクリップボード、名前付きクリップボード、変数、任意のテキスト、ファイル）を選び、次に **with**（処理内容）メニューからフィルターの種類を選びます。最後に、結果を元の場所に戻すか、別のクリップボード・変数・ファイルへ出力するかを指定します（[公式 Wiki](https://wiki.keyboardmaestro.com/action/Filter)）。よく使うフィルターには次のようなものがあります。

- **Remove Styles**：書式を取り除き、プレーンテキストにします（クリップボード専用）。
- **Trim Whitespace**：先頭と末尾の空白を取り除きます。
- **Uppercase**、**Lowercase**、**Title Case**、**Sentence Case**：大文字・小文字を切り替えます（すべて大文字、すべて小文字、各単語の先頭を大文字、文頭を大文字）。
- **Sort Lines**：各行を順番に並べ替えます。
- 文字数・単語数・行数のカウント。

全一覧は公式 Wiki の [Filters](https://wiki.keyboardmaestro.com/manual/Filters) ページに載っています。たとえば、先生が表計算ソフトから生徒の名前の列をコピーした場面を考えてみてください。1つ目の **Filter** で余分な空白を取り除き、2つ目の **Filter** で行を並べ替え、最後に貼り付けるだけで書類に収まります。たった3つのアクションです。「貼り付けるときに書式だけ消したい」という場合は、専用のハウツー記事もあります：[書式なしで貼り付ける](/ja/howto/paste-plain/)。

自分で作ったマクロを、先ほどの歯車メニューに表示させることもできます。マクロに **Clipboard Filter**（クリップボードフィルター）トリガーを付けておけばメニューに並び、一覧で選んだ項目に対して実行できるようになります（[公式 Wiki](https://wiki.keyboardmaestro.com/trigger/Clipboard_Filter)）。

## 内容は覚えているのに何番目か忘れたとき：Paste by Name

履歴を40番目までスクロールして探すのは大変です。そんなときは **Paste by Name**（名前で貼り付け）アクションを使うと、代わりに検索欄が開きます。覚えている言葉を少し入力するとクリップボード履歴から一致するテキストを探してくれるので、選んで貼り付けるだけです（[公式 Wiki](https://wiki.keyboardmaestro.com/action/Paste_by_Name)）。ホットキー付きのマクロにしておけば、「検索してから貼り付ける」専用キーが手に入ります。

これで、コピーしたものはいつでも取り戻せるようになり、よく使うものにも決まった置き場所ができました。ただ、マクロが増えてくると、思うように動かない場面にも必ず出会います。次のステップでは、マクロがうまく動かないときにどの順番で確認すればいいかを見ていきます。

## つまずいたときは

<Q q="⌃⇧⌘V を押しても何も出てきません。">
<p>まず、メニューバーに Keyboard Maestro のアイコンがあるか確認してください。なければエンジンが動いていません。次にエディタを開き、Switcher Group とその中にある Clipboard History Switcher マクロの両方が有効になっているかを確かめます。それでも出ないときは、<a href="/ja/guide/6-debug/">ステップ6</a>の手順どおりに確認してみてください。</p>
</Q>
<Q q="再起動すると、クリップボード履歴が空になります。">
<p>設定の General にある Save Clipboard History Between Launches がオフになっています。オンにしておけば、エンジンが終了して再起動しても履歴が残ります。</p>
</Q>
<Q q="特定のアプリでコピーした内容だけ履歴に残りません。">
<p>設定の Excluded を確認してみてください。そのアプリがクリップボード履歴の除外リストに入っている可能性があります。除外されたアプリが手前にある間、Keyboard Maestro はクリップボードを自動記録しません。</p>
</Q>
<Q q="さっきコピーした文字列が伏せられていて、しばらくしたら消えていました。">
<p>パスワードらしい内容と判断されたため、Keyboard Maestro が中身を伏せ、10番目に下がった時点で削除し、ディスクにも保存しなかったのです。確認したいときは ⌥ Option を押しながらクリックします。</p>
</Q>
<Q q="マクロで2つの文章を連続して貼り付けると、2つ目だけが2回貼り付けられます。">
<p>公式 Wiki によると、クリップボードへの書き換えは一瞬で終わる一方、⌘V の貼り付けはアプリ側の処理待ちになります。アプリの反応が遅いと、1回目の貼り付けが実行される前に2回目の書き換えまで終わってしまい、2つ目の文章が2回貼り付けられてしまうのです。1つの Insert Text by Pasting にまとめるか、2つのアクションの間に Pause（一時停止）を入れてみてください（<a href="https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted">公式 Wiki</a>）。</p>
</Q>
<Q q="Default Clipboard に内容を入れたのに、⌘V で貼り付けられません。">
<p>Default Clipboard はごく普通の名前付きクリップボードで、システムクリップボードではありません。貼り付けるには、Named Clipboard Switcher か Paste from Named Clipboard アクションを使います。</p>
</Q>
