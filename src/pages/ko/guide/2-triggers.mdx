하루를 마무리할 때 정리해 주는 매크로를 하나 만들었다고 해 봐요. 오늘 다운로드 폴더에 쌓인 파일을 한 폴더로 모아 주는 매크로예요. 아주 잘 작동하지만, 정작 실행하는 걸 자꾸 깜빡하게 돼요. 퇴근할 무렵이면 마음이 이미 책상을 떠나 있으니까요. 사실 이런 일은 굳이 기억해 둘 필요가 없어요. 오후 5시 30분이 되면 알아서 실행되게 두면 그만이에요.

반대인 매크로도 있어요. 긴 주소를 언제 입력해야 할지는 본인만 알 수 있지, Mac이 대신 알아맞힐 수는 없어요. 이럴 때는 시작하는 순간을 직접 알려 주어야 해요. 몇 글자만 입력하면 그다음부터 매크로가 이어서 처리해 주죠.

<mark><strong>트리거를 고른다는 건 그 작업이 가장 자연스럽게 시작되는 순간을 고르는 일이에요. 직접 실행하고 싶을 때는 단축키나 몇 글자 입력, 클릭을 쓰고, 정해진 시간이 되었을 때는 시계를, Mac 자체에 변화가 생겼을 때는 그 이벤트를 쓰면 돼요.</strong></mark>

## 트리거 추가하기

<Term k="触发器" text="트리거" />는 매크로 상세 영역에서 매크로 이름 바로 아래에 있어요. 초록색 **+**(**New Trigger**, 새 트리거) 버튼을 클릭하고 메뉴에서 원하는 종류를 고르세요. **Status Menu Trigger**(상태 메뉴 트리거)처럼 추가하자마자 바로 쓸 수 있는 것도 있지만, 대부분은 어떤 단축키를 쓸지, 어떤 문자열을 입력할지 같은 세부 설정을 한두 가지 채워 넣어야 해요. 자세한 내용은 공식 [Macro Triggers](https://wiki.keyboardmaestro.com/manual/Macro_Triggers) 문서를 참고하세요.

매크로 하나에는 트리거를 여러 개 둘 수 있고, 그중 어느 하나만 일어나도 매크로가 실행돼요. 예를 들어 “창 정리하기” 매크로 하나를 단축키로 실행하게 하면서, 로그인할 때도 알아서 한 번 실행되도록 설정할 수 있어요.

알아 두면 편한 요령이 하나 있어요. 트리거 메뉴에서 항목을 고를 때 Option 키(⌥)를 누른 채 클릭하면, 트리거가 추가되는 대신 Keyboard Maestro가 그 트리거의 공식 위키 페이지를 바로 열어 줘요. 이 페이지에서는 먼저 알아 둘 만한 트리거만 다루니, 나머지는 이 방법으로 찾아보는 게 가장 빨라요.

그리고 [1단계](/ko/guide/1-groups/)에서 다룬 규칙도 꼭 기억하세요. 트리거는 매크로가 사용(켬) 상태이고, 매크로 그룹 역시 사용(켬) 상태이면서 지금 활성 상태일 때만 작동해요.

## 직접 실행할 때: 단축키, 문자열 입력, 클릭

가장 많이 쓰는 건 **Hot Key Trigger**(단축키 트리거)예요. 지정해 둔 키 조합을 누르면 시스템이 그 입력을 맨 앞의 앱에 넘기지 않고 가로챈 다음, Keyboard Maestro가 매크로를 실행해요. 키는 글자, 숫자, 기호, 기능 키 모두 쓸 수 있고, 보통 보조 키(⌃ Control, ⌥ Option, ⇧ Shift, ⌘ Command)를 하나 이상 조합해요. 숫자 키패드의 숫자는 기본 키보드의 숫자와 서로 다른 키로 인식돼요. Control 키 하나만 누르는 것처럼 보조 키 단독으로는 단축키를 만들 수 없어요. 자세한 내용은 공식 [Hot Key Trigger](https://wiki.keyboardmaestro.com/trigger/Hot_Key) 문서를 보세요.

“누르면 바로 실행” 외에도 키에서 손을 뗄 때 실행하거나, 누르고 있는 동안 계속 반복하거나, 길게 눌렀을 때, 또는 두세 번 연달아 눌렀을 때만 실행하게 설정할 수도 있어요. 하지만 어느 방식을 고르든 그 키 입력은 Keyboard Maestro가 가로채기 때문에 원래 하던 역할은 못 하게 돼요. 그러니 평소 다른 용도로 쓰는 키는 단축키로 지정하지 마세요.

공식 위키에서는 단축키를 고를 때 두 가지 팁을 권해요. 첫째, 규칙을 정해 두는 거예요. 예를 들어 글자 입력용 매크로는 Control에 글자 하나를, 앱 열기용 매크로는 Control-Option에 글자 하나를 조합하고, 무슨 일을 하는지 떠오르는 글자를 고르는 식이죠. 둘째, 자주 쓰는 명령 키나 시스템 기본 단축키는 피하는 거예요. 이 사이트의 예시에서는 다른 앱이 거의 쓰지 않는 조합인 ⌃⌥⌘에 글자 하나를 더해 써요. 만약 다른 앱에도 똑같은 단축키가 등록되어 있다면, 그 키를 눌렀을 때 양쪽 동작이 모두 실행돼요.

일상에서 자주 쓰는 또 하나의 트리거는 **Typed String Trigger**(문자열 입력 트리거)예요. 어디서든 정해 둔 문자열을 입력하면 바로 작동하고, 보통은 방금 친 글자를 지운 뒤 매크로를 실행해요. 그래서 약어 기능으로 쓰기에 딱 좋아요. `=addr=`만 입력해도 전체 주소가 나오는 식이죠. 자세한 내용은 공식 [Typed String Trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String) 문서를 참고하거나, [입문 레슨 2](/ko/start/2-type-less/)에서 처음부터 직접 만들어 보세요.

공식 위키에서는 실수로 칠 일이 없는 기호를 문자열 앞이나 뒤, 혹은 양쪽에 붙이라고 특별히 권해요. 예를 들어 이메일 주소 약어를 `em`으로 정하면 “them”을 칠 때도 작동해 버리니, 대신 `=em=`처럼 쓰라는 거예요. 이 사이트의 예시도 모두 이 방식을 따라 양쪽에 등호를 붙여 `=addr=`, `=sig=`처럼 써요.

문자열을 입력하는 도중에 몇 가지 행동이 끼어들면 인식이 끊겨요. Shift-Space를 누르거나, Control이나 Command가 포함된 키를 누르거나, 다른 앱으로 전환하거나, 마우스를 클릭하거나, 몇 초 넘게 멈춰 있으면 취소돼요. 반대로 바뀌지 않게 `=addr=` 그대로 입력하고 싶다면, 중간에 Shift-Space를 한 번 눌렀다가 지우면 돼요. 또 암호 입력 칸에서는 작동하지 않고, Keyboard Maestro 자체 창에서도 잘 작동하지 않아요.

가끔만 써서 단축키를 외우기 어려운 매크로라면 클릭해서 실행할 수 있는 곳에 두세요. **Status Menu Trigger**를 쓰면 메뉴 막대의 Keyboard Maestro 아이콘 아래 메뉴, 즉 <Term k="状态菜单" text="상태 메뉴" />에 매크로가 들어가서 이름을 선택하기만 하면 실행돼요. 공식 위키에 따르면 파일 열기나 처리, 창 정리처럼 “메뉴 명령” 같은 느낌의 매크로에 잘 어울린다고 해요. **Global Macro Palette Trigger**(전역 매크로 팔레트 트리거)는 화면 위에 떠 있는 팔레트에 매크로를 올려 두고 클릭해서 실행하게 해 줘요. 두 가지 모두 지금 활성 상태인 매크로만 보여 줘요. 그래서 매크로 그룹을 Safari에서만 쓸 수 있게 설정해 두었다면, Safari가 맨 앞에 있을 때만 나타나요. 항목을 Option 키를 누른 채 클릭하면 그 매크로 편집 화면으로 바로 이동해요.

## 정해진 시간이 되었을 때: 시계

페이지 맨 앞에서 이야기한 퇴근 전 정리 매크로는 **Time of Day Trigger**(특정 시각 트리거)를 써요. 시각을 고른 뒤 요일을 체크하기만 하면 돼요. 자세한 내용은 공식 [Time of Day Trigger](https://wiki.keyboardmaestro.com/trigger/Time_of_Day) 문서를 보세요.

먼저 알아 두어야 할 특징이 하나 있어요. 정해진 시각에 Mac이 깨어 있어야 한다는 거예요. Mac이 잠자기 상태라면 그 차례는 그냥 지나가 버리고, 나중에 깨어나더라도 밀린 실행을 대신해 주지는 않아요. 화면이 잠겨 있거나 화면 보호기가 켜져 있을 때는 매크로 자체는 실행되지만, 글자를 입력하거나 메뉴를 고르는 것처럼 화면 인터페이스를 조작하는 동작은 상당수가 제대로 작동하지 않아요.

“매일 몇 시”가 아니라 “일정 간격마다” 실행하고 싶다면 **Periodic Trigger**(주기 트리거)를 쓰세요. 몇 초, 몇 분, 몇 시간마다 실행할지 정할 수 있고, 원하면 하루 중 특정 시간대나 특정 요일로 제한할 수도 있어요. 공식 위키에서는 몇 초마다 한 번처럼 간격을 너무 짧게 잡지 말라고 권해요. CPU를 많이 쓰고 다른 작업도 방해할 수 있거든요. 또 자정을 넘기는 시간대는 자정에서 멈추므로, 계속 이어서 실행하려면 트리거를 하나 더 추가해야 해요. 자세한 내용은 공식 [Periodic Trigger](https://wiki.keyboardmaestro.com/trigger/Periodic) 문서를 참고하세요.

두 가지가 더 있어요. **Idle Trigger**(유휴 상태 트리거)는 자리를 20분쯤 비운 것처럼 키보드와 마우스를 한동안 건드리지 않았을 때 실행돼요. cron 문법을 알고 있다면 **Cron Trigger**(크론 트리거)도 쓸 수 있어요. 예약 실행 매크로를 처음부터 끝까지 따라 해 보려면 활용법의 [매일 같은 시간에 실행하기](/ko/howto/daily-schedule/)를 보세요.

## Mac 자체에 변화가 생겼을 때

직접 무언가를 누르는 순간도, 정해진 시각도 아니라 Mac 자체에 작은 변화가 생겼을 때 시작하는 작업도 있어요.

**Application Trigger**(앱 트리거)는 특정 앱(또는 아무 앱이나)이 열리거나 종료될 때, 맨 앞으로 나오거나 뒤로 갈 때 실행돼요. 그 앱이 실행 중이거나 맨 앞에 있는 동안 일정 간격마다 실행되게 할 수도 있어요. 예를 들어 미리보기를 열 때마다 창을 화면 오른쪽 절반으로 끌어다 놓는다면, 이 일을 앱 트리거에 맡기면 돼요. [1단계](/ko/guide/1-groups/)에서 짚었던 함정도 잊지 마세요. 특정 앱이 열리기를 기다리는 매크로는 반드시 항상 활성 상태인 매크로 그룹에 넣어 두어야 해요. 자세한 내용은 공식 [Application Trigger](https://wiki.keyboardmaestro.com/trigger/Application) 문서를 보세요.

**Login Trigger**(로그인 트리거)는 로그인과 함께 엔진이 시작될 때 실행돼요. 보통 **Launch Engine at Login**(로그인 시 엔진 실행)을 켜 두었기 때문에 함께 시작되죠. 공식 위키에서는 평소 익숙한 상태로 Mac을 세팅해 두는 용도로 추천해요. 비슷한 트리거로는 **Wake Trigger**(잠자기에서 깰 때), **Sleep Trigger**(잠자기에 들 때), **Unlock Trigger**(화면 잠금을 풀 때)가 있어요.

**Wireless Network Trigger**(무선 네트워크 트리거)는 Wi-Fi 네트워크에 연결되거나 연결이 끊어질 때 실행돼요. 노트북이 회사 네트워크에 연결되면 업무용 앱들을 열고, 집 네트워크에 연결되면 다른 앱 구성으로 바꾸는 식이죠. 네트워크 이름으로 구분할 수도 있지만, 공식 위키에서는 BSSID로 구분하는 쪽을 더 권해요. “Home”이나 “Work” 같은 이름을 쓰는 네트워크가 워낙 많으니까요. 두 가지를 더 알아 두세요. macOS 14부터는 Keyboard Maestro Engine에 위치 권한을 주어야 Wi-Fi 정보를 읽을 수 있어요. 또 Mac은 잠자기에 들었다가 깨어날 때마다 Wi-Fi를 끊었다가 다시 연결하기 때문에, 이런 매크로는 여러 번 실행되어도 문제없도록 만들어 두어야 해요. 자세한 내용은 공식 [Wireless Network Trigger](https://wiki.keyboardmaestro.com/trigger/Wireless_Network) 문서를 참고하세요.

**USB Device Trigger**(USB 기기 트리거)는 USB 기기를 꽂거나 뺄 때 실행돼요. 공식 위키에서는 스캐너 전원을 켜면 스캔 앱을 자동으로 열고, 끄면 종료하는 예를 들어요. 기기 이름은 짐작하기 어려우니, 이름 입력 칸에 커서를 둔 채 기기를 연결해 보세요. 그러면 Keyboard Maestro가 이름을 알아서 채워 줘요. 디스크의 경우에는 **Mounted Volume Trigger**(디스크 마운트 트리거)를 쓰면 돼요. 예를 들어 백업 디스크를 꽂자마자 백업을 시작하게 할 수 있죠. Wi-Fi와 USB 매크로를 처음부터 끝까지 따라 해 보려면 활용법의 [Wi-Fi에 연결되거나 기기를 꽂았을 때 실행하기](/ko/howto/wifi-usb/)를 보세요.

**Folder Trigger**(폴더 트리거)는 폴더에 항목이 추가되거나 사라질 때 실행돼요. 다운로드 폴더에 새 파일이 들어왔을 때 제자리로 옮겨 주는 일이 대표적이죠. 이 트리거는 지정한 폴더 자체만 지켜볼 뿐, 그 안의 하위 폴더에서 생긴 변화는 신경 쓰지 않아요. 또 파일 다운로드나 복사가 완전히 끝날 때까지 기다렸다가 실행하게 설정할 수도 있어서, 절반만 받아진 파일을 건드리는 일을 막을 수 있어요. 다만 파일 변화가 멈출 때까지 기다려야 확실히 알 수 있기 때문에 실행이 조금 늦어져요. 자세한 내용은 공식 [Folder Trigger](https://wiki.keyboardmaestro.com/trigger/Folder) 문서와 활용법의 [폴더에 파일이 들어오자마자 정리하기](/ko/howto/watch-folder/)를 보세요.

이런 종류의 트리거는 이 밖에도 많아요. 디스플레이가 연결되거나 분리될 때(**Display Layout Changed Trigger**), 전원 어댑터를 꽂거나 뺄 때(**Power Status Changed Trigger**), 헤드폰을 꽂는 것처럼 사운드 출력이 바뀔 때(**Audio Output Device Changed Trigger**), 클립보드 내용이 바뀔 때(**Clipboard Changed Trigger**), 시스템이 라이트 모드와 다크 모드 사이를 전환할 때(**Appearance Changed Trigger**)도 트리거로 쓸 수 있어요.

## 다른 프로그램이 호출할 때

마지막 유형은 다른 무언가가 매크로를 시작하게 하는 방식이에요. 다른 매크로가 동작을 통해 이름으로 호출하거나, AppleScript나 셸 명령으로 부르거나, `kmtrigger://`로 시작하는 URL로 실행하거나, 심지어 다른 기기의 브라우저에서 원격으로 실행할 수도 있어요. 이런 방식은 스크립트와 네트워크가 엮여 있으니 [7단계](/ko/guide/7-advanced/)에서 자세히 다룰게요.

## 나머지는 공식 목록에서 찾아보세요

Keyboard Maestro에는 트리거가 30가지 넘게 있어요. 이 페이지에 다 적지는 않았고, 전부 외울 필요도 없어요. 필요할 때 Option 키를 누른 채 트리거 메뉴에서 골라 보거나, 트리거마다 개별 설명 페이지가 정리되어 있는 공식 [Triggers](https://wiki.keyboardmaestro.com/Triggers) 목록을 훑어보세요.

이번 단계의 핵심은 딱 하나예요. 어떤 작업이 가장 자연스럽게 시작되는 순간이 언제인지 먼저 떠올리고, 그 순간에 맞는 트리거를 찾는 거예요. 다음 단계에서는 매크로가 시작된 뒤에 실제로 일을 해내는 동작을 알아볼게요.

## 막혔나요?

<Q q="단축키를 눌렀는데 아무 일도 일어나지 않아요.">
<p>먼저 매크로와 매크로 그룹이 모두 사용(켬) 상태이고, 지금 매크로 그룹이 활성 상태인지 확인해 보세요. 예를 들어 그룹에 포함되지 않은 앱에서 단축키를 누르고 있는 건 아닌지 살펴보세요. 그런 다음 <strong>Help ▸ Interactive Help</strong>(도움말 ▸ 대화형 도움말)을 선택하면 권한, 매크로 그룹, 트리거를 하나씩 점검해 어디서 막혔는지 알려 줘요. 전체 점검 방법은 <a href="/ko/guide/6-debug/">6단계</a>에 정리되어 있어요.</p>
</Q>
<Q q="약어를 입력했는데 아무 일도 일어나지 않아요.">
<p>입력하는 도중에 몇 초 멈추거나 마우스를 클릭하거나 앱을 전환하면 모두 취소되니 처음부터 다시 입력해 보세요. 암호 입력 칸에서는 원래 작동하지 않고, Keyboard Maestro 자체 창에서도 잘 작동하지 않아요. 어느 곳에서도 전혀 작동하지 않는다면, 시스템이 계속 암호 입력 칸에 있다고 착각해 ‘보안 입력(Secure Input)’ 모드에 걸려 있을 수 있어요. <strong>Help ▸ Interactive Help</strong>로 이 상태를 확인할 수 있어요. 자세한 내용은 공식 <a href="https://wiki.keyboardmaestro.com/Troubleshooting">Troubleshooting</a> 문서를 참고하세요.</p>
</Q>
<Q q="원하지 않는 곳에서 약어가 자동으로 바뀌어 버려요.">
<p>설정한 문자열이 평소에 입력하는 글자와 겹치기 때문이에요. 공식 위키의 권고대로 그냥 <code>sig</code> 대신 <code>=sig=</code>처럼 실수로 칠 일이 없는 기호를 앞뒤에 붙여 보세요.</p>
</Q>
<Q q="시간을 정해 둔 매크로가 어젯밤에 실행되지 않았어요.">
<p>그때 Mac이 잠자기 상태였을 가능성이 커요. 예정된 시각에 Mac이 잠들어 있으면 그 차례는 지나가 버리고, 깨어난 뒤에도 대신 실행되지 않아요. 화면이 잠겨 있을 때는 매크로가 실행되지만, 글자 입력이나 메뉴 선택 같은 동작은 작동하지 않아요.</p>
</Q>
<Q q="Wi-Fi에 연결했는데 매크로가 반응하지 않아요.">
<p>macOS 14부터는 Keyboard Maestro Engine에 위치 권한이 있어야 Wi-Fi 정보를 읽을 수 있어요. <strong>시스템 설정 ▸ 개인정보 보호 및 보안</strong>의 위치 서비스에서 켜져 있는지 확인해 보세요. 목록에 아예 보이지 않는다면, 개발사가 안내하는 해결 방법대로 매크로에서 <strong>Get Location</strong>(위치 가져오기) 동작을 한 번 실행해 보세요. 그러면 시스템이 권한을 묻는 창을 띄워 줘요(<a href="https://wiki.keyboardmaestro.com/Frequently_Asked_Questions">공식 FAQ</a>).</p>
</Q>
<Q q="매크로가 두 번 실행됐어요.">
<p>로그인할 때와 Wi-Fi에 연결될 때처럼, 매크로에 달린 트리거 두 개가 공교롭게 둘 다 일어나지는 않았는지 확인해 보세요. Wi-Fi 트리거는 Mac이 잠자기에 들었다가 깨어날 때마다 다시 작동하므로, 이런 매크로는 여러 번 실행되어도 괜찮게 만들어 두어야 해요.</p>
</Q>
