하루에 메모 앱을 몇 번이나 여나요? 문득 생각이 하나 떠오르면 마우스를 Dock으로 내려 노란색 아이콘을 찾아 클릭하고, 창이 뜨길 기다려요. 한 번에 몇 초밖에 안 걸리지만 하루에도 열 번 넘게 이 일을 반복하다 보면, 창이 뜰 즈음엔 방금 떠오른 생각이 날아가 버리곤 해요.

이 레슨을 마칠 때쯤이면 ⌃⌥⌘N을 누르는 것만으로 메모가 맨 앞으로 올라와요. 메모가 꺼져 있다면 먼저 열어 주기까지 해요. 그 전에 세 가지만 준비하면 돼요. Keyboard Maestro를 설치하고, 권한을 켜고, 백그라운드에서 계속 실행되게 설정하는 거예요. 세 가지 모두 처음에 한 번만 해 두면 돼요.

## 매크로는 “이럴 때, 이걸 한다” 한 문장이에요

Keyboard Maestro가 대신 해 주는 일 하나하나를 <Term k="宏" text="매크로" />라고 불러요. 아무리 복잡한 매크로라도 딱 두 부분으로 나뉘어요. 언제 시작할지 정하는 실행 계기가 <Term k="触发器" text="트리거" />이고, 시작한 뒤에 무엇을 할지가 <Term k="动作" text="동작" />이에요. 동작은 하나일 수도 있고 여러 개가 줄줄이 이어질 수도 있는데, 위에서 아래로 순서대로 실행돼요([공식 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)).

그래서 지금 만들 매크로도 한 문장으로 딱 정리돼요.

<mark><strong>⌃⌥⌘N을 누르면 메모를 맨 앞으로 불러온다.</strong></mark>

⌃는 Control 키, ⌥는 Option 키, ⌘는 Command 키예요. 이 세 키를 한꺼번에 누른 채 알파벳 키를 누르는 조합은 다른 앱이 거의 쓰지 않아서 단축키가 겹칠 일이 드물어요. 메모는 예시일 뿐이에요. 평소 가장 자주 여는 앱이 Mail이나 캘린더, 텍스트 편집기라면 그 앱으로 바꿔도 나머지 단계는 모두 똑같아요.

## 내려받은 뒤 Finder로 응용 프로그램 폴더에 옮기기

Keyboard Maestro는 공식 사이트인 [keyboardmaestro.com](https://www.keyboardmaestro.com/)에서 내려받으면 돼요. Mac App Store에는 올라와 있지 않은데, 개발사 설명에 따르면 스토어가 요구하는 샌드박스 제한에 맞출 수 없기 때문이에요([공식 안내](https://wiki.keyboardmaestro.com/manual/How_do_I)). macOS 10.13 이상이 필요하고, 구매하기 전까지는 모든 기능을 쓸 수 있는 체험판으로 작동해요([공식 안내](https://wiki.keyboardmaestro.com/manual/Purchase)).

내려받은 파일은 zip 압축 파일이에요. 더블클릭해서 압축을 풀면 Keyboard Maestro 앱이 나와요. 다음 단계는 절대 건너뛰지 마세요. <u>Finder로 앱을 응용 프로그램 폴더에 끌어다 놓은 뒤, 거기서 열어 주세요.</u> macOS에는 App Translocation이라는 보안 기능이 있어요. 인터넷에서 받은 앱을 옮기지 않고 바로 열면 시스템이 임의의 위치에서 앱을 실행하는데, 그러면 로그인 시 자동 실행이 안 되고 이후 업데이트도 실패해요. Finder로 한 번 옮겨 주면 이 제한이 풀리지만, 다른 방법으로 옮기면 풀리지 않아요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#App_Translocation_Security)).

## 앱을 열면 사실 두 프로그램이 함께 켜져요

Keyboard Maestro를 열었을 때 눈앞에 뜨는 창이 <Term k="编辑器" text="편집기" />예요. 여기서 매크로를 만들고 고쳐요. 이와 동시에 두 번째 프로그램인 **Keyboard Maestro Engine**, 즉 <Term k="引擎" text="엔진" />도 조용히 함께 켜져요. 엔진은 창이 따로 없고 백그라운드에 머물면서, 누르는 단축키를 기다렸다가 매크로를 실행해요([공식 안내](https://wiki.keyboardmaestro.com/manual/How_do_I)).

이 역할 분담을 기억해 두면 나중에 많은 부분이 금방 이해돼요. 편집을 마치고 편집기를 종료해도 매크로는 계속 작동해요. 실제 일은 엔진이 하거든요. 반대로 엔진이 꺼져 있으면 어떤 매크로도 움직이지 않아요.

처음 열면 **Start Tutorial**(튜토리얼 시작) 버튼이 있는 환영 창이 떠요. 공식 내장 튜토리얼인데 이 레슨과 내용이 거의 비슷하니, 나중에 봐도 괜찮아요.

## 권한 켜기

Keyboard Maestro는 대신 키를 누르고 메뉴를 선택하고 창을 옮겨요. 내 대신 Mac을 조작하는 셈이라 macOS가 직접 허락을 받으려고 해요. 이것이 <Term k="辅助功能权限" text="손쉬운 사용 권한" />이에요. 이 권한이 없으면 Keyboard Maestro가 키보드 입력을 읽지 못해서 단축키조차 등록할 수 없어요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)).

처음 열면 Keyboard Maestro가 이 권한을 켜 달라고 알려 줘요. 아직 빠진 권한이 있으면 편집기 창 오른쪽 아래에 작은 노란색 삼각형이 떠 있어요. 그걸 클릭해서 안내를 따라가도 되고, 직접 설정해도 돼요.

1. **시스템 설정 ▸ 개인정보 보호 및 보안 ▸ 손쉬운 사용**을 여세요. 구버전 macOS에서는 **시스템 환경설정**의 보안 및 개인 정보 보호 ▸ 개인 정보 보호에 있어요.
2. 목록에서 **Keyboard Maestro Engine**을 찾아 켜세요. 목록에 **Keyboard Maestro**도 있다면 함께 켜 주세요. macOS가 로그인 암호를 물어볼 수도 있어요.

<Callout type="ok">
Keyboard Maestro로 돌아와 보면 오른쪽 아래의 노란색 삼각형이 사라졌을 거예요. 아직 남아 있다면 클릭해서 어떤 항목이 빠졌는지 확인해 보세요.
</Callout>

앞으로 특정 앱을 처음 제어하거나 특정 시스템 기능을 처음 쓸 때 macOS가 권한을 한 번 더 물어볼 수 있어요. 정상적인 과정이에요([공식 FAQ](https://wiki.keyboardmaestro.com/Frequently_Asked_Questions)). 요청한 앱이 Keyboard Maestro가 맞는지 확인한 뒤 허용해 주세요.

## 로그인할 때 엔진이 자동으로 켜지게 하기

엔진은 로그아웃하거나 Mac을 끌 때까지 계속 켜져 있어요. 하지만 다음에 Mac을 다시 켤 때는 따로 설정해 두지 않으면 저절로 실행되지 않아요. 개발사에서도 이 옵션을 켜 두라고 권해요([공식 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)).

1. Keyboard Maestro에서 **Keyboard Maestro ▸ Settings…**(Keyboard Maestro ▸ 설정…)을 선택하세요. 구버전 macOS에서는 Preferences…라고 표시돼요.
2. **General**(일반) 탭에서 **Launch Engine at Login**(로그인 시 엔진 실행)을 체크하세요.

이제 Mac을 켤 때마다 엔진이 백그라운드에서 대기하고 있어서, 로그인하자마자 매크로가 바로 작동해요.

## 첫 매크로 만들기

편집기 창은 세 칸으로 나뉘어 있어요. 왼쪽은 매크로를 담아 두는 폴더 같은 <Term k="宏组" text="매크로 그룹" /> 목록이고, 가운데는 선택한 그룹 안에 들어 있는 매크로 목록이에요. 오른쪽에는 선택한 매크로의 내용이 표시돼요.

1. 왼쪽 칸에서 **Global Macro Group**(전역 매크로 그룹)을 선택하세요. 이 그룹에 넣은 매크로는 모든 앱에서 작동해요.
2. 가운데 칸 아래에 있는 **+** 버튼을 클릭해 새 매크로를 추가하세요. “메모 열기”처럼 알아보기 쉬운 이름을 붙여 주세요.
3. 오른쪽에서 초록색 **+** 버튼인 **New Trigger**(새 트리거)를 클릭하고, **Hot Key Trigger**(단축키 트리거)를 선택하세요. 빈 입력 칸이 나타나면 그 안을 클릭한 뒤 ⌃⌥⌘N을 누르세요. 방금 누른 키 조합이 칸 안에 표시돼요.
4. **New Action**(새 동작)을 클릭하세요. 창 왼쪽에 긴 동작 목록이 열려요. 여기서 **All Actions**(모든 동작) 분류를 선택하세요. 알파벳순으로 정렬되어 있어서 **Activate a Specific Application**(특정 앱 활성화)가 맨 위쪽 몇 개 안에 바로 보일 거예요. 그걸 더블클릭하세요.
5. 이 동작의 **Activate:**(활성화) 메뉴에서 메모를 선택하세요.

Keyboard Maestro에는 따로 저장 버튼이 없어요. 무엇을 바꾸든 몇 초 뒤에 저절로 저장돼요([공식 Quick Start](https://wiki.keyboardmaestro.com/manual/Quick_Start)). 매크로는 만들자마자 바로 작동하고, 뭔가를 다시 시작할 필요도 없어요.

## 시험해 보기

데스크탑을 클릭하거나 다른 아무 앱으로 전환한 뒤 ⌃⌥⌘N을 눌러 보세요.

<Callout type="ok">
메모가 맨 앞으로 올라와요. ⌘Q로 메모를 종료한 뒤 다시 한 번 눌러 보면 메모가 열려요.
</Callout>

작은 실험을 하나 더 해 볼까요. **Keyboard Maestro ▸ Quit Keyboard Maestro**(Keyboard Maestro 종료)를 선택해 편집기를 닫은 뒤, ⌃⌥⌘N을 다시 눌러 보세요. 메모가 똑같이 뜰 거예요. 단축키를 기다렸다가 일을 처리하는 건 백그라운드의 엔진이니까요.

방금 Keyboard Maestro를 설치하고, 권한을 켜고, 로그인 시 엔진이 자동으로 켜지게 설정한 데다 첫 매크로까지 만들었어요. 단축키 하나에 동작 하나였죠. 다음 레슨에서는 다른 종류의 트리거를 써서, 몇 글자만 치면 문단 하나가 통째로 입력되게 만들어 볼 거예요.

<Callout type="tip" title="세 레슨이면 충분해요">
레슨 2에서는 몇 글자만 치면 문단 하나가 통째로 나오는 매크로를 만들어요. 레슨 3에서는 하루를 시작할 때 늘 여는 것들을 매크로 하나로 묶고, 실행 중인 매크로를 멈추는 법과 매크로가 작동하지 않을 때 확인할 곳도 배워요. 이 세 레슨만 마치면 직접 매크로를 만들 수 있어요. 사이트의 나머지 내용은 필요할 때 찾아보면 돼요.
</Callout>

## 뭔가 잘 안 될 때

<Q q="⌃⌥⌘N을 눌렀는데 아무 일도 일어나지 않아요.">

가장 빠른 방법은 Keyboard Maestro가 직접 점검하게 하는 거예요. 편집기를 열고 **Help ▸ Interactive Help**(도움말 ▸ 대화형 도움말)을 선택한 뒤, “Something expected is not happening”(예상한 일이 일어나지 않음)을 클릭하세요. 그러면 엔진이 켜져 있는지와 권한이 허용돼 있는지를 먼저 확인하고, 이어서 해당 매크로를 고르게 한 다음 그 매크로가 속한 그룹과 매크로 자체가 켜져 있는지, 트리거와 동작이 들어 있는지를 하나씩 점검해 줘요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#Macros_Not_Firing_Triggered)). 거기서 짚어 주는 항목만 고치면 돼요.

</Q>
<Q q="단축키 입력 칸을 클릭하고 키를 눌러도 아무것도 뜨지 않아요.">

거의 대부분 손쉬운 사용 권한 때문이에요. 권한이 없으면 Keyboard Maestro가 키보드 입력을 읽지 못해요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key)). 위의 “권한 켜기” 부분을 다시 확인해 보세요. 권한이 다 켜져 있는데도 계속 이렇다면, 시스템이 지금 암호를 입력 중이라고 착각한 상태일 수 있어요. 바로 다음 항목을 확인해 보세요.

</Q>
<Q q="시스템 설정에서 분명히 켰는데도 Keyboard Maestro가 권한이 없다고 해요.">

개발사에서도 Mojave 이후로 macOS 권한 시스템에 버그가 많다고 솔직히 말해요. 체크해 뒀는데 실제로는 적용되지 않거나, 권한이 없는데도 시스템이 Keyboard Maestro에 권한이 있다고 잘못 알려 주는 식이에요([공식 안내](https://wiki.keyboardmaestro.com/manual/Troubleshooting)). 공식 안내에서 권하는 방법들을 순서대로 해 보세요. **손쉬운 사용**에서 **Keyboard Maestro Engine**을 껐다가 다시 켜 보세요. 그래도 안 되면 Keyboard Maestro와 엔진을 모두 종료했다가 다시 열고, 마지막으로 Mac을 재시동해 보세요.

가능성이 하나 더 있어요. 어떤 앱이 시스템에 계속 암호를 입력 중이라는 신호를 남겨 두면, 그때는 어떤 프로그램도 키보드 입력을 볼 수 없게 돼요. 이를 Secure Input이라고 해요. 해당 앱을 종료하거나 Mac을 재시동하면 풀리고, **Help ▸ Interactive Help**에서 “Something unexpected is happening”(예상치 못한 일이 일어남)을 눌러 보면 이 문제가 원인인지 알려 줘요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode)).

</Q>
<Q q="편집기에서 App Translocation 경고가 뜨거나, 재시동한 뒤 매크로가 작동하지 않아요.">

대부분 앱이 아직 다운로드 폴더에 있거나, Finder가 아닌 다른 방법으로 응용 프로그램 폴더에 옮겨졌기 때문이에요. Keyboard Maestro를 먼저 종료한 뒤 Finder에서 응용 프로그램 폴더로 끌어다 놓고, 거기서 다시 열어 주세요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#App_Translocation_Security)). 그런 다음 **Launch Engine at Login**이 체크되어 있는지 확인하세요.

</Q>
<Q q="오늘 Mac을 켰더니 단축키가 하나도 안 먹어요.">

로그인할 때 엔진이 함께 켜지지 않아서 그래요. Keyboard Maestro를 한 번 열면 엔진도 같이 켜져요. 그다음 **Keyboard Maestro ▸ Settings…** 메뉴의 **General** 탭에서 **Launch Engine at Login**을 체크해 두면 다음부터는 신경 쓰지 않아도 돼요([공식 안내](https://wiki.keyboardmaestro.com/Troubleshooting#Macros_Not_Firing_After_You_Login)).

</Q>
<Q q="단축키를 눌렀더니 메모도 열리면서 다른 앱도 같이 뭔가를 실행해요.">

다른 앱도 ⌃⌥⌘N을 시스템 전역 단축키로 등록해 둔 상태예요. 개발사 설명에 따르면 두 프로그램이 같은 단축키를 등록해 놓으면 내 매크로와 그 앱의 기능이 동시에 실행돼요([공식 안내](https://wiki.keyboardmaestro.com/trigger/Hot_Key)). 트리거 입력 칸을 클릭해서 ⌃⌥⌘에 다른 알파벳을 붙이는 식으로 다른 조합으로 바꿔 주면 돼요.

</Q>
<Q q="단축키를 눌렀더니 매크로 목록이 작게 뜨면서 고르라고 나와요.">

두 매크로가 같은 단축키를 쓰고 있어서 그래요. Keyboard Maestro가 어느 쪽을 실행하려는 건지 알 수 없어 둘 다 보여 주는 거예요([공식 안내](https://wiki.keyboardmaestro.com/trigger/Hot_Key)). 둘 중 하나의 단축키를 다른 조합으로 바꾸면 그 목록은 다시 뜨지 않아요.

</Q>
