부모님 병원 서류를 챙기다 보면 검사 결과지, 처방전, 퇴원 요약서 같은 문서를 하나씩 스캔해 두게 되는데요. 스캐너가 붙여 주는 이름은 기껏해야 Scan 1.pdf, Scan 2.pdf, Scan 3.pdf… 식이에요. 병원에 몇 번만 다녀와도 파일이 수십 개씩 쌓이고, 반년 뒤에 지난 혈액검사 결과를 찾으려면 결국 하나씩 열어 볼 수밖에 없죠. 일일이 손으로 이름을 바꾸다 보면 열 개째쯤엔 손이 뻐근해져요. 이걸 매크로로 만들어 두면 Finder에서 파일들을 한꺼번에 선택하고 ⌃⌥⌘R(Control, Option, Command를 누른 채 R)을 누르기만 하면 돼요. 앞에 무엇을 붙일지 물어볼 때 “아빠 11월 검진”이라고 입력하면, 선택한 파일 전체가 “아빠 11월 검진 Scan 1.pdf” 같은 이름으로 한 번에 바뀌어요.

<mark>파일 여러 개의 이름을 바꾸는 일은 결국 선택한 파일 하나하나에 똑같은 작업을 반복하는 거예요.</mark>

<u>먼저 복사본에서 시험해 보세요.</u> 이름 바꾸기는 디스크에 있는 실제 파일을 직접 바꾸는 작업이라서, 매크로에 실수가 있으면 선택한 파일 전체가 똑같이 잘못 바뀌어 버려요. Finder에서 그 폴더를 하나 복제해 두고, 복사본에서 만족스러울 때까지 시험해 본 다음에 실제 파일에 적용하세요.

## For Each: 항목마다 한 번씩 실행하기

“항목마다 한 번씩 실행하기”를 Keyboard Maestro에서는 **For Each**(하나씩 반복)이라고 해요. 항목 목록을 넘겨주면 하나씩 꺼내 <Term k="变量" text="변수" />에 담은 뒤, 그 안에 들어 있는 동작들을 차례로 실행해 줘요([For Each](https://wiki.keyboardmaestro.com/action/For_Each) 참고).

그럼 그 목록은 어디서 가져올까요? For Each에서 **The Finder’s selection**(Finder의 선택 항목)을 고르면 지금 Finder에서 선택해 둔 항목들이 목록이 돼요. 공식 문서에 따르면 이때 변수에는 각 파일의 전체 경로, 즉 디스크 최상위부터 파일 이름까지 이어지는 긴 경로 문자열이 들어가요([Working with the Finder Selection](https://wiki.keyboardmaestro.com/collection/Finders_Selection) 참고). 선택한 파일들의 이름을 일정한 규칙으로 바꾸는 것도 공식 문서에서 소개하는 대표적인 활용 예 중 하나예요.

경로를 얻고 나면 남은 단계는 두 가지예요. 그 경로에서 원래 파일 이름을 꺼내고, 새 이름으로 바꿔 주면 돼요.

## 매크로 만들기

먼저 “파일 이름 앞에 문구 붙이기”라는 이름으로 새 매크로를 만드세요. Finder에서만 작동하게 하고 싶다면 **Available in these applications:** Finder(다음 앱에서만 활성: Finder)로 설정한 매크로 그룹에 넣으면 돼요. 트리거로는 **Hot Key**(단축키)를 추가하고 ⌃⌥⌘R로 지정하세요. 그런 다음 아래 동작들을 차례대로 추가해요.

**첫째, 앞에 붙일 문구를 물어봐요**. **Prompt for User Input**(사용자 입력 요청)을 추가해 제목에 “파일 이름 앞에 문구 붙이기”라고 적고, 그 아래 `Prefix`라는 변수를 하나 추가하세요. 기본값에는 “아빠 11월 검진”처럼 자주 쓰는 문구를 넣어 두면 편해요. 매크로가 이 단계에 이르면 작은 창이 하나 열리는데, 필요하면 문구를 고친 뒤 **OK**(확인)을 누르면 돼요. **Cancel**(취소)를 누르면 파일은 하나도 건드리지 않고 매크로 전체가 멈춰요([Prompt for User Input](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input) 참고).

**둘째, 하나씩 처리해요**. **For Each**를 추가하고 변수 칸에 `FilePath`를 입력한 뒤, 컬렉션 옆의 +를 눌러 **The Finder’s selection**을 선택하세요. 이어지는 두 동작은 모두 이 For Each 안에 넣어야 해요.

**셋째, 원래 이름을 꺼내요**. For Each 안에 **Split Path**(경로 나누기)를 추가하고, 나눌 경로에는 아래 내용을 넣으세요.

<Copy id="rf-path" title="나눌 경로" code="%Variable%FilePath%" />

이 동작은 경로를 파일이 들어 있는 폴더, 파일 이름, 확장자를 뺀 이름, 확장자 이렇게 여러 부분으로 나눠 주고, 각 부분을 원하는 변수에 저장할 수 있어요([Split Path](https://wiki.keyboardmaestro.com/action/Split_Path) 참고). 여기서는 **File Name**(파일 이름)만 필요하니 `FileName`이라는 변수에 저장하세요. 확장자까지 포함된 `Scan 1.pdf` 같은 값이 들어가요.

**넷째, 이름을 바꿔요**. 이어서 **File Actions**(파일 동작)을 추가하고 **Rename**(이름 바꾸기)를 선택하세요. 대상 파일에는 `%Variable%FilePath%`를 넣고, 새 이름에는 아래 내용을 적어요.

<Copy id="rf-new" title="새 이름" code="%Variable%Prefix% %Variable%FileName%" />

`%Variable%Prefix%`는 <Term k="令牌" text="토큰" />이에요. 매크로가 실행될 때 그 변수 안에 들어 있는 글자로 바뀌어요. 공식 문서에 따르면 **Rename**의 새 이름에는 슬래시 없이 순수하게 파일 이름만 적어야 해요. 그래서 파일은 원래 폴더에 그대로 남고 이름만 바뀌게 돼요([File Actions](https://wiki.keyboardmaestro.com/action/File_Actions) 참고).

## 잘 작동하는지 확인하기

복사해 둔 폴더에서 파일 세 개를 선택하고 ⌃⌥⌘R을 눌러 보세요. 앞에 붙일 문구를 묻는 작은 창이 열릴 거예요. 원하는 문구를 입력하고 **OK**를 누르면, Finder에서 선택한 파일 세 개의 이름 맨 앞에 방금 입력한 글자가 붙고 원래 이름과 확장자는 그대로 남아 있어요. 선택하지 않은 파일 이름은 그대로예요.

새 이름 칸에는 다른 토큰도 넣을 수 있어요. 맨 앞에 오늘 날짜까지 붙이고 싶다면 `%ICUDateTime%yyyy-MM-dd% %Variable%Prefix% %Variable%FileName%`처럼 적으면 돼요. 날짜 형식을 바꾸는 법은 [키 하나로 오늘 날짜 넣기](/ko/howto/insert-date/)를 참고하세요.

## 막혔나요?

<Q q="⌃⌥⌘R을 눌렀고 입력 창도 떴는데, 파일 이름이 하나도 안 바뀌어요.">
For Each는 단축키를 누른 바로 그 순간 Finder에서 선택되어 있는 항목을 가져와요. 우선 Finder에서 파일을 실제로 선택했는지 확인해 보세요. 매크로 그룹을 Finder에서만 작동하도록 설정했다면 단축키를 누를 때 Finder가 맨 앞에 나와 있어야 해요. 그리고 셋째와 넷째 동작이 For Each 뒤에 나란히 놓인 게 아니라 For Each 안에 제대로 들어 있는지도 확인해 보세요.
</Q>
<Q q="중간에 멈춰서 어떤 파일은 바뀌고 어떤 파일은 그대로예요.">
이름이 겹쳤을 가능성이 높아요. 공식 문서에 따르면 새 이름과 똑같은 파일이 그 폴더에 이미 있으면 이 단계에서 오류가 나며 매크로가 그대로 멈춰요. 어느 파일에서 멈췄는지 살펴보고 중복된 이름을 정리한 뒤, 아직 바뀌지 않은 파일만 다시 선택해서 실행하세요.
</Q>
<Q q="함께 선택한 폴더 이름까지 바뀌어 버렸어요.">
**The Finder’s selection**은 선택된 항목이면 무엇이든 그대로 넘겨주고, **Rename**은 파일뿐 아니라 폴더에도 똑같이 작동해요. 이름을 바꿀 파일만 선택해서 실행하세요.
</Q>
<Q q="파일들이 다른 폴더로 옮겨져 버렸어요.">
**Move or Rename**(이동 또는 이름 바꾸기)를 선택했는데 새 이름에 슬래시가 들어가서 파일이 그쪽으로 이동했을 가능성이 커요. **Rename**을 사용하고, 새 이름에는 파일 이름만 적으세요.
</Q>

For Each를 익혀 두면 “하나하나 똑같이 처리하기”는 다 같은 방식으로 만들 수 있어요. 파일 여러 개에 태그를 붙이거나 한곳으로 옮기는 작업도 안에 들어가는 동작만 바꾸면 돼요. 파일이 폴더에 들어오자마자 자동으로 처리되게 하고 싶다면 [폴더에 파일이 들어오자마자 정리하기](/ko/howto/watch-folder/)를 이어서 보세요.
