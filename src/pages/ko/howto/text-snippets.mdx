작은 온라인 상점을 운영하다 보면 하루 종일 비슷한 답장 몇 가지를 반복해서 보내게 돼요. 주문해 주셔서 감사하다, 영업일 기준 이틀 안에 발송된다, 운송장 번호는 이메일로 보내 드린다는 식이죠. 하루에 메일 스무 통을 답장하면 이 문장을 스무 번 쳐야 하고, 바쁘게 치다 보면 문장 반쪽을 빼먹기도 해요. 이 페이지를 따라 해 두고 나면 Mail이나 글자를 입력할 수 있는 어느 곳에서든 `=ship=`이라고 치기만 해도 그 여섯 글자가 저절로 지워지면서 답장 전체로 바뀌어요. 서명과 교환·반품 안내에도 각자 약어를 붙여 둘 수 있어요.

아직 약어를 한 번도 만들어 본 적이 없다면 [입문 레슨 2](/ko/start/2-type-less/)부터 보고 오세요. 거기서는 편집기를 여는 것부터 차근차근 알려 줘요. 이 페이지에서는 그다음 단계를 다뤄요. 약어가 여러 개 생겼을 때 이름을 어떻게 지으면 좋은지, 긴 글은 왜 붙여넣기로 넣어야 하는지, 그리고 애초에 약어가 먹히지 않는 곳은 어디인지 알아볼게요.

## 왜 앞뒤에 등호를 붙일까요

<Term k="输入字符串触发器" text="문자열 입력 트리거" />는 내가 치는 모든 글자를 지켜보고 있다가, 방금 입력한 마지막 몇 글자가 지정해 둔 문자열과 일치하는 순간 매크로를 실행해요. 그래서 평소에 자주 쓰는 평범한 단어를 약어로 정해 두면 원치 않을 때도 자꾸 실행돼 버려요. 공식 문서에서도 이메일 주소 약어로 `em`을 정했다가 “them”을 칠 때마다 매크로가 실행되는 예를 들고 있어요. 그래서 공식 문서에서는 `=em=`처럼 평소에는 실수로 칠 일이 없는 일정한 접두사나 접미사를 약어에 붙이라고 권해요([Typed String trigger](https://wiki.keyboardmaestro.com/trigger/Typed_String) 참고).

<mark>앞뒤에 등호를 하나씩 붙여 두면, 약어는 내가 부를 때만 나타나요.</mark> 이 사이트의 예제는 모두 이런 방식을 써요. `=ship=`, `=sig=`, `=ret=`처럼요. 한 가지 규칙으로 통일해 두면 외우기도 편해서, 등호를 치는 순간부터 약어를 부르고 있다는 걸 바로 알 수 있어요.

## 배송 안내 답장부터 만들어 봐요

먼저 약어들을 모아 둘 자리부터 만들어요. 편집기 왼쪽 매크로 그룹 목록 아래쪽의 + 버튼을 클릭해서 “상용구”라는 새 <Term k="宏组" text="매크로 그룹" />을 만들어요. 새로 만든 매크로 그룹은 기본적으로 모든 앱에서 작동하게 되어 있어서 지금 상황에 딱 맞아요. 답장을 Mail에서 쓸 때도 있고, 웹 페이지 문의 창에서 쓸 때도 있으니까요.

이제 그 그룹 안에 새 매크로를 만들고, 나중에 목록에서 한눈에 알아볼 수 있도록 이름을 “=ship= 배송 안내 답장”으로 지어요. 트리거를 추가해서 **Typed String**(문자열 입력)을 고른 다음, **This string is typed:**(이 문자열을 입력할 때) 뒤에 `=ship=`을 입력해요. 그 아래에 있는 **Simulate 6 deletes before executing**(실행 전 삭제 키 6번 누르기)에도 체크가 되어 있는지 확인하세요. 여기서 숫자는 약어의 글자 수에 따라 자동으로 바뀌는데, 이 항목을 체크해 두어야 `=ship=`이 먼저 지워지고 그 자리에 답장이 들어가요. 이어서 **Insert Text by Pasting**(붙여넣기로 텍스트 삽입) 동작을 추가하고 그 안에 답장 내용을 적어요.

<Copy id="ts-ship" title="=ship= 대신 들어가는 답장" code="주문해 주셔서 감사합니다! 영업일 기준 2일 안에 발송해 드리고, 발송되면 운송장 번호를 바로 이메일로 보내 드릴게요. 궁금한 점이나 문제가 생기면 이 메일로 바로 답장해 주세요." />

Keyboard Maestro에는 따로 저장 버튼이 없어요. 내용을 고치면 몇 초 뒤에 알아서 저장돼요.

## 타이핑 대신 붙여넣기를 쓰는 이유

글자를 넣을 때 자주 쓰는 동작은 두 가지예요. **Insert Text by Typing**(타이핑으로 텍스트 삽입)은 사람이 직접 키를 하나씩 누르는 것처럼 글자를 입력해요. 키를 한두 번 눌러서 칠 수 있는 문자로 이루어진 30~40자 안팎의 짧은 글에 알맞고, 그보다 길어지면 느려지는 데다 이모지는 입력하지 못해요. 반면에 **Insert Text by Pasting**은 글자를 클립보드에 넣은 뒤 대신 ⌘V(⌘는 Command 키예요)를 눌러 줘요. 그래서 아무리 긴 글이라도 한 번에 나오고, 어떤 문자든 상관없으며, 줄바꿈도 웹 페이지의 버튼을 눌러 버리는 Return 키처럼 작동하지 않고 줄바꿈 그대로 들어가요. 다만 클립보드에 원래 들어 있던 내용이 덮어씌워진다는 단점이 있어요. 두 동작의 자세한 비교는 공식 [Insert Text](https://wiki.keyboardmaestro.com/action/Insert_Text) 페이지에서 볼 수 있어요.

답장이나 서명은 길고 여러 줄인 경우가 많아서 약어에는 **Insert Text by Pasting**을 쓰는 게 가장 마음 편해요. 클립보드 내용이 바뀌는 것도 크게 걱정할 필요 없어요. Keyboard Maestro의 <Term k="剪贴板历史" text="클립보드 기록" />에 이전에 복사해 둔 내용이 남아 있으니 필요할 때 다시 꺼내 쓰면 돼요. 자세한 내용은 [전체 가이드 5단계](/ko/guide/5-clipboard/)를 참고하세요.

## 두 개 더 만들기: 서명과 교환·반품 안내

같은 그룹 안에 똑같은 방식으로 매크로를 두 개 더 만들어 봐요. 서명은 세 줄짜리라서 붙여넣기의 장점이 잘 드러나요. 줄바꿈이 하나도 빠지지 않고 그대로 들어가요.

<Copy id="ts-sig" title="=sig= 대신 들어가는 서명" code={`좋은 하루 보내세요.
미아 드림
초록모퉁이 상점, 월~금 9:00~18:00 답변`} />

교환·반품 안내는 두 번째로 자주 보내는 답장이니 `=ret=` 약어를 붙여 줘요.

<Copy id="ts-ret" title="=ret= 대신 들어가는 교환·반품 안내" code="받으신 상품에 문제가 있다면 사진을 찍어 이 메일로 답장해 주세요. 새 상품으로 다시 보내 드리거나 환불해 드릴게요. 왕복 배송비는 제가 부담할게요." />

약어 자체는 영문자와 기호로만 만드는 게 좋아요. 공식 문서에서도 트리거에 ASCII가 아닌 문자가 들어가면 삭제가 제대로 작동하는지 직접 확인해야 한다고 주의를 주고 있어요. 영문자와 기호만 쓰면 그런 문제를 겪을 일이 없어요.

## 잘 작동하는지 확인해 봐요

Mail을 열고 새 메일 작성 창을 띄운 뒤, 본문에 `=ship=`을 쳐 보세요. 여섯 글자가 순식간에 사라지면서 답장 전체가 나타나는 걸 볼 수 있어요. 그 아래에 `=sig=`를 치면 세 줄짜리 서명이 적은 그대로 나와요.

친구에게 이 방법을 알려 줄 때처럼 어쩌다 `=ship=`이라는 글자 자체를 그대로 쳐야 할 때도 있죠. 이럴 때 쓰라고 공식 문서에서 알려 주는 요령이 있어요. 중간에 ⇧Space(⇧는 Shift 키예요)를 한 번 눌렀다가 지우는 거예요. 예를 들어 `=sh`까지 친 뒤 ⇧Space를 누르고 지운 다음, 이어서 `ip=`를 입력하는 식이죠. ⇧Space가 입력 흐름을 끊어 주기 때문에 약어가 실행되지 않아요.

## 막혔나요?

<Q q="약어를 쳤는데 아무 일도 일어나지 않아요.">
먼저 약어를 끊지 않고 한 번에 다 쳤는지 떠올려 보세요. 중간에 몇 초 멈추거나, 마우스를 클릭하거나, ⌘나 ⌃(Control) 키가 들어간 조합을 누르거나, 다른 앱으로 전환하면 Keyboard Maestro가 지금까지 입력한 문자열을 버리고 처음부터 다시 세기 시작해요. 분명히 이어서 다 쳤는데도 반응이 없다면 권한 문제일 가능성이 커요. 문자열 입력 트리거도 단축키와 마찬가지로 내가 치는 글자를 읽으려면 <Term k="辅助功能权限" text="손쉬운 사용 권한" />이 필요하거든요. **Help ▸ Interactive Help**(도움말 ▸ 대화형 도움말)을 선택하고 Something unexpected is happening(예상치 못한 문제가 발생함)을 클릭하면 뚜렷한 원인이 있을 때 바로 알려 줘요. 공식 안내는 [Troubleshooting](https://wiki.keyboardmaestro.com/Troubleshooting#Not_Being_Able_To_Enter_a_Hot_Key) 페이지에서 확인할 수 있어요.
</Q>
<Q q="비밀번호 입력 칸이나 Keyboard Maestro 자체 창에서는 약어가 작동하지 않아요.">
일부러 그렇게 막혀 있는 거예요. macOS는 어떤 앱도 비밀번호 입력 칸에 치는 글자를 엿보지 못하게 막아 두기 때문에, 그 안에서는 약어가 절대 작동하지 않아요. Keyboard Maestro가 띄우는 팝업 창에서도 엔진이 입력 내용을 읽지 못하고, 편집기 안에서도 매끄럽게 작동하지 않아요. 그래서 공식 문서에서는 이런 곳에서는 다른 트리거를 쓰라고 권해요. 만약 어느 날 갑자기 모든 곳에서 약어가 먹히지 않는다면, 시스템이 아직 비밀번호 입력 칸에 머물러 있다고 착각하는 상태(Secure Input)일 수 있어요. 방금 전 비밀번호를 물었던 앱을 종료하거나 Mac을 재시동하면 대개 해결돼요. 자세한 내용은 [Troubleshooting 페이지의 Secure Input Mode 항목](https://wiki.keyboardmaestro.com/Troubleshooting#Secure_Input_Mode)을 참고하세요.
</Q>
<Q q="스프레드시트나 파일 목록에서 약어를 쳤더니 다른 게 지워졌어요.">
**Simulate 6 deletes before executing**은 말 그대로 Keyboard Maestro가 대신 Delete 키를 몇 번 눌러 준다는 뜻이에요. 글자를 쓰는 칸이 아닌 곳에서는 이렇게 Delete 키를 누르다가 선택되어 있던 항목이 지워질 수 있고, 공식 문서에서도 바로 이 점을 경고하고 있어요. 약어는 글을 쓰는 곳에서만 사용하거나, 해당 매크로에서 이 항목의 체크를 해제해 두세요.
</Q>
<Q q="지난번에 복사한 내용이 그대로 붙여넣어졌어요.">
어떤 앱은 붙여넣기 처리가 조금 느려요. 클립보드 내용은 이미 바뀌었는데 ⌘V가 아직 제때 적용되지 못해서 엉뚱한 내용이 들어가 버리는 거죠. 특히 약어 두 개를 연달아 실행할 때 이런 일을 겪기 쉬워요. 공식 문서의 [Sometimes the Wrong Thing is Pasted](https://wiki.keyboardmaestro.com/Troubleshooting#Sometimes_the_Wrong_Thing_is_Pasted) 항목에서는 함께 나와야 할 글은 하나의 동작에 몰아넣어 한 번에 붙여넣거나, 두 붙여넣기 동작 사이에 **Pause**(일시 정지)를 넣으라고 안내해요.
</Q>

이제 가장 자주 쓰는 문구마다 앞뒤에 등호가 붙은 이름이 하나씩 생겼어요. 글 안에 오늘 날짜를 넣고 싶다면 이어서 [키 하나로 오늘 날짜 넣기](/ko/howto/insert-date/)를 읽어 보세요.
