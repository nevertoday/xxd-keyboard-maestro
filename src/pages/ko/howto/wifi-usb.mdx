가르치는 일을 한다면 한 번쯤 겪어 봤을 거예요. 노트북을 프로젝터에 연결하고 덮개를 열자마자 어젯밤에 틀어 둔 음악이 교실 가득 울려 퍼지고, 큰 화면에 이메일 알림이 연달아 뜨는 상황 말이에요. 교실에 들어갔을 때 해야 할 일은 소리를 끄고 Mail을 종료하는 것, 딱 두 가지뿐인데 바쁜 날엔 깜빡하기 쉬워요. 이 페이지를 다 보고 나면 아무것도 누르지 않아도 MacBook이 학교 Wi-Fi에 연결되자마자 스스로 음소거하고 Mail을 종료해요.

시간 트리거는 “지금 몇 시인가”를 맡아요. 이 페이지의 두 <Term k="触发器" text="트리거" />는 “어디에 있는지, 무엇이 연결돼 있는지”를 맡아요. <mark>어딘가에 도착하거나 무언가를 연결할 때마다 늘 하는 일이라면, 그 네트워크나 그 기기가 시작 버튼을 누르게 해 두세요.</mark>

## 학교 Wi-Fi에 연결되면 음소거하고 Mail 종료하기

“교실 들어가기”라는 이름으로 새 <Term k="宏" text="매크로" />를 만들어요. 트리거는 **Wireless Network**(무선 네트워크)를 고르세요. Wi-Fi 네트워크에 연결되거나 연결이 끊어질 때 실행되는 트리거예요([Wireless Network 트리거](https://wiki.keyboardmaestro.com/trigger/Wireless_Network)). 어떤 네트워크에든 반응하게 할 수도 있고, 이름이 일치하는 네트워크에만 반응하게 할 수도 있어요. 공식 위키에서는 BSSID를 쓰는 쪽을 더 권하는데, “Home”이나 “Work” 같은 이름의 네트워크는 워낙 많아서 더 고유한 식별자인 BSSID가 낫기 때문이에요.

이름은 직접 입력하지 않아도 돼요. 트리거의 이름 입력 칸에 커서를 둔 채로 메뉴 막대에서 학교 Wi-Fi 연결을 끊었다가 다시 연결하면, Keyboard Maestro가 네트워크 이름(또는 BSSID)을 대신 채워 줘요. 연결될 때 실행되도록 설정하세요.

이제 동작을 두 개 추가할게요. **Mute Audio Device**(오디오 기기 음소거)는 기본 오디오 기기를 음소거하거나, 음소거를 해제하거나, 두 상태를 전환할 수 있어요(Keyboard Maestro 11 이상, [Mute Audio Device](https://wiki.keyboardmaestro.com/action/Mute_Audio_Device)). 여기서는 음소거를 선택하세요. 이어서 **Quit a Specific Application**(특정 앱 종료)를 추가해 Mail을 고르고, 옵션은 **Quit**(종료)로 두세요. 수업이 끝난 뒤 원래대로 되돌리고 싶다면 “교실 나오기”라는 두 번째 매크로를 만들어 같은 네트워크 연결이 끊어질 때 음소거를 해제하도록 설정하면 돼요.

macOS Sonoma부터는 빼놓을 수 없는 단계가 하나 더 있어요. Wi-Fi 정보를 읽으려면 위치 권한이 필요하거든요. 공식 위키에서도 **시스템 설정 ▸ 개인정보 보호 및 보안**의 위치 서비스에서 Keyboard Maestro Engine에 권한이 켜져 있는지 확인하라고 안내해요. 이 권한이 없으면 엔진이 Wi-Fi 정보를 읽지 못해요.

<Callout type="ok">
교실에서 Wi-Fi를 껐다가 다시 켜 보세요. 학교 네트워크에 다시 연결되면 소리 아이콘이 음소거 상태로 바뀌고 Mail이 종료돼요.
</Callout>

## 여러 번 실행되니, 반복돼도 안전하게 만들기

공식 위키에서도 이 점을 따로 강조해요. Mac은 잠자기에 들어갔다가 깨어날 때마다 Wi-Fi를 끊었다가 다시 연결하고, macOS가 뒤에서 조용히 재연결할 때도 있어요. 그래서 이런 매크로는 여러 번 실행돼도 안전해야 해요. 음소거와 Mail 종료는 문제없어요. 이미 음소거된 상태를 한 번 더 음소거하거나 이미 닫혀 있는 앱을 다시 종료해도 아무 탈이 없거든요. 하지만 여기에 “오늘 수업 노트 새로 만들기” 같은 동작을 넣어 두면, 노트북 덮개를 닫을 때마다 파일이 하나씩 더 생겨요. 몇 번을 실행해도 결과가 똑같은 동작을 고르세요.

## 스캐너를 켜면 스캔 앱 열기

이번엔 다른 분의 경우를 볼게요. 학교에 다니는 아이가 있다면 저녁에 서류 몇 장을 스캔할 일이 종종 있을 거예요. 그럴 때마다 스캐너를 켜고, 스캔 앱을 찾아서 열고, 다 끝나고 나면 앱을 닫는 걸 깜빡하곤 하죠. **USB Device**(USB 기기) 트리거는 USB 기기가 연결되거나 분리될 때 매크로를 실행해요. 공식 위키에 실린 예시가 바로 이거예요. 스캐너를 켜면 스캔 소프트웨어를 실행하고, 끄면 종료하는 거죠([USB Device 트리거](https://wiki.keyboardmaestro.com/trigger/USB_Device)).

USB 기기 이름은 생각한 것과 다른 경우가 많아서, 이것도 Keyboard Maestro가 직접 채우게 두세요. 트리거의 이름 입력 칸에 커서를 두고 스캐너를 연결하거나 전원을 켜면 이름이 바로 들어가요. 매크로는 두 개로 나누어 두면 깔끔해요. 하나는 기기가 연결될 때 실행되게 하고 **Activate a Specific Application**(특정 앱 활성화) 동작에 스캔 앱을 지정해요. 앱이 아직 열려 있지 않다면 알아서 실행해 줘요. 다른 하나는 기기가 분리될 때 실행되게 하고, 같은 앱을 대상으로 **Quit a Specific Application**을 넣어요. 매크로가 실행되는 동안 `%TriggerValue%` <Term k="令牌" text="토큰" />에는 기기 이름이 담겨 있으니, 알림에 어떤 기기인지 함께 표시하고 싶을 때 유용해요.

기다리는 대상이 기기가 아니라 외장 드라이브나 카드 리더기에 꽂은 메모리 카드 같은 디스크라면, **Mounted Volume**(마운트된 볼륨) 트리거를 쓰는 게 맞아요. 특정 볼륨 하나든 아무 볼륨이든, 볼륨이 마운트되거나 마운트 해제될 때 실행돼요([Mounted Volume 트리거](https://wiki.keyboardmaestro.com/trigger/Mounted_Volume)).

## 다른 매크로 안에서 상태만 확인하기

연결되자마자 매크로가 실행될 필요까지는 없는 경우도 있어요. 예를 들어 아침 알림이 집에서는 뜨고 학교에서는 안 뜨게 하는 것처럼, 다른 매크로가 상황에 맞춰 다르게 움직이기만 하면 되는 거죠. 이럴 때는 조건을 쓰면 돼요. **Wireless Network** 조건으로 특정 네트워크에 연결돼 있는지 확인하고, **USB Device** 조건으로 특정 기기가 연결돼 있는지 확인해서 **If Then Else**(조건 분기) 동작과 함께 쓰는 거예요([Wireless Network 조건](https://wiki.keyboardmaestro.com/condition/Wireless_Network), [USB Device 조건](https://wiki.keyboardmaestro.com/condition/USB_Device)). 조건이 무엇이고 어떻게 쓰는지 궁금하다면 [전체 가이드 4단계](/ko/guide/4-variables/)를 참고하세요.

## 막혔나요?

<Q q="네트워크에 연결했는데 매크로가 실행되지 않아요.">
macOS Sonoma 이상에서는 먼저 Keyboard Maestro Engine에 위치 권한이 있는지 확인하세요. 그다음 트리거에 적힌 이름이 네트워크 이름과 정확히 일치하는지 살펴보세요. 가장 확실한 방법은 입력 칸을 비우고 커서를 둔 뒤, Wi-Fi를 끊었다가 다시 연결해서 자동으로 채워지게 하는 거예요. 매크로와 해당 <Term k="宏组" text="매크로 그룹" />이 모두 사용(켬) 상태인지도 확인하세요.
</Q>
<Q q="매크로가 하루에도 몇 번씩 실행돼요.">
자연스러운 현상이에요. 잠자기, 깨어나기, 그리고 시스템의 자동 재연결이 일어날 때마다 매크로가 다시 실행되거든요. 여러 번 반복돼도 괜찮은 동작으로 바꾸고, 파일을 새로 만들거나 메시지를 보내는 동작은 이런 매크로에 넣지 마세요.
</Q>
<Q q="스캐너 이름이 생각한 것과 다르고, 직접 입력해도 작동하지 않아요.">
이름을 직접 입력하지 말고 기기를 연결할 때 Keyboard Maestro가 채워 넣게 두세요. 공식 위키에서도 기기를 꽂거나 전원을 켜는 두 방식 모두 인식된다고 하니, 전원 버튼이 있는 스캐너라면 먼저 커서를 입력 칸에 둔 뒤 전원을 켜 보세요.
</Q>
<Q q="외장 드라이브를 연결했는데 USB Device 트리거가 아무 반응이 없어요.">
디스크가 연결되기를 기다릴 때는 볼륨 이름을 기준으로 인식하는 **Mounted Volume** 트리거가 더 잘 맞아요.
</Q>

네트워크 하나, 기기 하나만 있어도 알아서 시작 버튼을 눌러 줄 수 있어요. 정해진 시각이 되면 매크로가 자동으로 시작되게 하고 싶다면 [매일 같은 시간에 실행하기](/ko/howto/daily-schedule/)를 참고하세요.
