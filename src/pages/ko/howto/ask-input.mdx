구직 활동을 하다 보면 하루에도 여러 곳에 지원 메일을 보내게 되는데, 메일 첫 몇 줄은 사실 매번 똑같아요. 바뀌는 건 회사 이름과 직무, 그리고 공고를 어디서 보았는지 정도뿐이죠. 이전 메일을 복사해서 고쳐 쓰면 되긴 하지만, 한 군데라도 놓치면 다른 회사 이름이 그대로 들어간 메일을 보내게 돼요. 이 페이지를 끝까지 따라 하고 나면, 새 메일에서 ⌃⌥⌘L(Control, Option, Command, L)을 눌렀을 때 작은 입력 폼이 먼저 떠서 그 세 가지를 물어봐요. 내용을 채우고 Return을 누르면 이름이 하나도 틀리지 않은 정중한 첫인사가 커서 위치에 바로 나타나요.

지금까지 만든 매크로는 한 번에 끝까지 쭉 실행됐어요. <mark>먼저 한마디 물어본 뒤 그 답을 받아 이어서 작업하게 만들면, 매번 거의 비슷하지만 조금씩 다른 일도 매크로가 처리할 수 있어요.</mark>

## 먼저 작은 입력 폼으로 물어보기

“지원 메일 첫인사”라는 이름으로 새 <Term k="宏" text="매크로" />를 만들고, **Hot Key**(단축키) 트리거를 추가한 뒤 ⌃⌥⌘L을 눌러 등록하세요. 첫 번째 동작은 **Prompt for User Input**(사용자 입력 요청)이에요. 직접 구성한 입력 폼을 화면에 띄우고, 입력한 내용을 <Term k="变量" text="변수" />에 저장해 주는 동작이죠([Prompt for User Input 동작](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input)).

입력 폼 맨 위에는 제목을 적는 칸이 있으니 “지원 메일 첫인사”라고 쓰세요. 그 아래 안내 문구 칸에는 본인이 볼 짧은 문장을 적으면 되는데, 예를 들어 “이번 메일은 어디에 보내나요?”처럼 쓰면 돼요. 그 밑으로는 변수가 한 줄에 하나씩 들어가며, 왼쪽이 변수 이름이고 오른쪽이 기본값이에요. 아래 세 줄을 추가하세요.

- `Local Company`, 기본값은 비워 두세요.
- `Local Role`, 기본값은 비워 두세요.
- `Local Source`, 기본값은 `채용 사이트|지인 소개|회사 홈페이지`로 적으세요.

변수 이름 앞의 `Local`은 그냥 붙이는 말이 아니에요. Local로 시작하는 변수는 로컬 변수라서 이 매크로 안에서만 존재하다가 실행이 끝나면 사라지기 때문에, Mac에 불필요한 변수가 쌓이지 않아요. 또 입력 폼에 표시되는 라벨에서도 “Local”이 자동으로 빠져서, 화면에는 “Company”, “Role”, “Source”만 보여요([Variables](https://wiki.keyboardmaestro.com/manual/Variables), [Prompt for User Input 동작](https://wiki.keyboardmaestro.com/action/Prompt_for_User_Input)). 세 번째 기본값에는 세로줄 `|`이 들어 있어서 Keyboard Maestro가 이를 팝업 메뉴로 만들어 줘요. 세로줄이 선택지를 나누는 구분선 역할을 하고, 맨 앞에 적은 항목이 기본으로 선택돼요.

버튼은 기본으로 들어 있는 두 개면 충분해요. **OK**(확인)은 Return 키에 대응하며 입력 폼을 닫고 다음 동작으로 넘어가요. **Cancel**(취소)는 Escape나 ⌘.에 대응하며, 변수에 값을 저장하지 않은 채 입력 폼을 닫고 매크로 자체를 취소해요.

## 입력한 답을 문장에 채워 넣기

두 번째 동작은 **Insert Text by Pasting**(붙여넣기로 텍스트 삽입)이에요. 본문 안에 `%Variable%변수명%` 형식으로 쓰면 방금 입력한 답을 꺼내 올 수 있어요. 아래 내용을 본인 말투에 맞게 다듬어 써 보세요.

<Copy id="ai-letter" title="Insert Text by Pasting에 넣을 텍스트" code={`안녕하세요.

%Variable%Local Source%를 통해 %Variable%Local Company%에서 %Variable%Local Role% 직무를 채용 중이라는 소식을 접했습니다. 채용 공고를 읽어 보니 지난 몇 년간 해 온 업무와 잘 맞을 것 같아, 이력서를 첨부해 연락드립니다. 직접 이야기를 나눠 볼 기회가 있으면 좋겠습니다.`} />

사용할 때는 메일 본문 맨 앞에 커서를 둔 다음 ⌃⌥⌘L을 누르면 돼요.

<Callout type="ok">
“지원 메일 첫인사”라는 제목의 작은 창이 뜨고, 그 안에 텍스트 입력 칸 두 개와 팝업 메뉴 하나가 보여요. 내용을 채우고 Return을 누르면 창이 닫히면서, 세 군데가 모두 방금 입력한 내용으로 바뀐 첫인사가 메일에 나타나요.
</Callout>

보내기 전에는 꼭 한 번 읽어 보세요. 어느 자리를 바꿔야 하는지는 입력 폼이 기억해 주지만, 회사 이름이 맞는지, 어조가 알맞은지 확인하는 건 여전히 직접 해야 해요.

## 몇 가지 문장 중 하나만 고르기: Prompt With List

먼저 물어보는 방법에는 글자를 입력하지 않고 고르기만 하는 방식도 있어요. 작은 온라인 쇼핑몰을 운영하다 보면 고객에게 보내는 답변이 늘 몇 가지로 정해져 있잖아요. 이미 발송했다는 안내, 언제 도착하는지, 반품은 어떻게 하는지 같은 것들이죠. **Prompt With List**(목록에서 선택)은 Spotlight처럼 생긴 창에 선택지 목록을 띄워 줘요. 몇 글자만 입력해서 목록을 좁힌 뒤 하나를 골라 Return을 누르면 돼요([Prompt With List 동작](https://wiki.keyboardmaestro.com/action/Prompt_With_List)).

선택지는 한 줄에 하나씩 동작 안에 바로 적어 넣을 수 있어요. 창에 보이는 글자와 실제로 받아 오는 내용을 다르게 설정할 수도 있는데요. 한 줄을 “실제로 가져올 내용, 밑줄 두 개, 화면에 표시할 이름” 형식으로 쓰면 창에는 뒤쪽의 짧은 이름만 보이고, 그걸 선택했을 때 앞쪽의 전체 문장이 나와요. 예를 들면 이렇게 쓸 수 있어요.

<Copy id="ai-list" title="Prompt With List에 넣을 선택지" code={`주문하신 상품은 오늘 발송되었습니다. 운송장 번호는 주문 내역에서 확인하실 수 있으며, 보통 3~5일 안에 도착합니다.__발송 완료
택배가 현재 이동 중입니다. 배송 조회는 하루에 한 번 정도 업데이트되며, 변동이 생기면 바로 알려 드리겠습니다.__배송 중
받아 보신 뒤 마음에 들지 않으셔도 괜찮습니다. 편하게 연락 주시면 반품이나 교환 절차를 안내해 드리겠습니다.__반품·교환`} />

이 동작은 별도의 새 매크로에 넣고 전용 단축키를 지정하세요. 선택 결과는 `Local Reply` 같은 변수에 저장하고, 뒤에 **Insert Text by Pasting**을 붙여 본문에 `%Variable%Local Reply%`라고 적으면 돼요. Escape를 누르면 이 동작은 실패로 처리되어 아무것도 저장되지 않고, 기본 설정대로라면 실패 알림과 함께 매크로 전체가 취소돼요. 그러니 이 창에서도 Escape로 빠져나오면 돼요.

## 막혔나요?

<Q q="Cancel을 눌렀는데 아무것도 붙여넣기가 안 돼요.">
원래 그렇게 작동해요. Cancel은 변수에 값을 저장하지 않고 매크로 전체를 취소하거든요. 만약 “저장만 하고 붙여넣지는 않기”처럼 다른 일을 하는 세 번째 버튼이 필요하다면 입력 폼에 버튼을 더 추가하면 돼요. 어떤 버튼을 눌렀는지는 `%PromptButton%` <Term k="令牌" text="토큰" />에 이름이 담기니까, 뒤에 **If Then Else**(조건 분기)를 두어 버튼에 따라 흐름을 나눌 수 있어요.
</Q>
<Q q="%Variable%Local Company%라는 글자가 그대로 붙여넣어져요.">
입력 폼에 적은 변수 이름과 문장 안에 적은 이름이 한 글자도 틀리지 않고 똑같은지 확인해 보세요. `Local` 뒤의 띄어쓰기까지 일치해야 해요. 가장 안전한 방법은 직접 입력하지 않고 **Edit ▸ Insert Variable**(편집 ▸ 변수 삽입) 메뉴로 변수를 넣는 거예요([Variables](https://wiki.keyboardmaestro.com/manual/Variables)).
</Q>
<Q q="팝업 메뉴를 만들고 싶은데 텍스트 입력 칸이 나와요.">
항목 유형이 Automatic(자동)으로 되어 있으면 기본값을 보고 알아서 판단하는데, 세로줄이 들어 있어야만 메뉴로 만들어 줘요. 세로줄이 없거나 더 분명하게 지정하고 싶다면, 기본값 오른쪽에 있는 메뉴에서 Menu(메뉴)를 직접 선택하세요.
</Q>
<Q q="입력 폼은 열렸는데 안에서 약어가 펼쳐지지 않아요.">
공식 위키에 따르면, 시스템이 Keyboard Maestro Engine 자체 창에서 입력한 키를 보지 못하게 막아 두어서 이런 입력 폼 안에서는 문자열 입력 트리거가 작동하지 않아요. 입력 폼에 직접 입력하거나, 다른 곳에서 먼저 복사한 뒤 붙여넣어 쓰세요.
</Q>

입력 폼 하나와 변수 몇 개만 있으면 매번 달라지는 부분만 직접 채우고 나머지는 매크로에 맡길 수 있어요. 변수와 조건을 활용하면 훨씬 더 많은 일을 할 수 있으니 [전체 가이드 4단계](/ko/guide/4-variables/)도 살펴보세요.
